# display-settings Specification

## Purpose

설정 목록 화면과 화면 설정(테마 색, 달력 주 시작 요일)을 정의해, 근무 확인 화면과 설정 UI를 분리하고 앱의 강조색을 사용자가 고를 수 있게 한다.

## Requirements

### Requirement: 설정 목록 화면
저장된 설정이 있으면 달력 화면은 설정 목록 화면으로 들어가는 진입점을 SHALL 제공한다. 설정 목록 화면은 "근무 패턴"과 "화면 설정" 두 항목을 SHALL 표시하고, 각 항목을 누르면 해당 화면이 열린다.

#### Scenario: 설정 목록 진입
- **WHEN** 사용자가 달력 화면에서 설정 진입점을 누른다
- **THEN** "근무 패턴"과 "화면 설정" 항목이 있는 설정 목록 화면이 열린다

#### Scenario: 근무 패턴 열기
- **WHEN** 설정 목록에서 "근무 패턴"을 누른다
- **THEN** 저장된 패턴과 오늘 위치가 채워진 근무 패턴 설정 화면이 열린다

#### Scenario: 화면 설정 열기
- **WHEN** 설정 목록에서 "화면 설정"을 누른다
- **THEN** 현재 테마 색과 주 시작 요일이 선택된 화면 설정 화면이 열린다

### Requirement: 테마 색 선택
화면 설정은 인디고(`#4F46E5`), 딥 틸(`#0F766E`), 코랄 오렌지(`#C2410C`) 세 테마 색을 SHALL 제공하며 기본값은 인디고다. 각 선택지는 색 견본과 이름을 함께 표시해야 하고(MUST), 테마 목록에 토스 브랜드 색 계열을 포함해서는 MUST NOT 된다.

#### Scenario: 선택지 표시
- **WHEN** 화면 설정을 연다
- **THEN** 인디고·딥 틸·코랄 오렌지 세 선택지가 색 견본과 이름으로 표시되고 현재 테마가 선택되어 있다

#### Scenario: 설정 없는 기본값
- **WHEN** 테마를 고른 적 없는 사용자가 앱을 연다
- **THEN** 인디고 테마로 표시된다

### Requirement: 테마 즉시 적용과 저장
테마 색을 고르면 [저장] 없이 즉시 저장되고, 버튼·오늘 강조·선택된 칸 등 앱의 강조색과 TDS 컴포넌트 색에 SHALL 반영된다. 근무 유형 색은 테마와 무관하게 유지된다. 저장에 실패하면 이전 테마로 되돌리고 오류를 MUST 안내한다.

#### Scenario: 테마 변경
- **WHEN** 화면 설정에서 딥 틸을 고른다
- **THEN** 화면 설정의 버튼과 선택 표시가 즉시 딥 틸로 바뀌고, 달력으로 돌아가면 오늘 강조도 딥 틸이다

#### Scenario: 근무 유형 색 유지
- **WHEN** 테마를 코랄 오렌지로 바꾼다
- **THEN** 주간·야간·비번 등 근무 유형 칸의 색은 바뀌지 않는다

#### Scenario: 재실행 후 유지
- **WHEN** 테마를 딥 틸로 바꾼 뒤 앱을 다시 연다
- **THEN** 앱이 딥 틸 테마로 표시된다

#### Scenario: 저장 실패
- **WHEN** 테마를 바꿨으나 저장소 쓰기가 실패한다
- **THEN** 테마가 이전 값으로 되돌아가고 저장하지 못했다는 안내가 표시된다

### Requirement: 주 시작 요일 선택 위치
주 시작 요일(일요일/월요일) 선택은 화면 설정에서 SHALL 제공되며, [저장] 없이 즉시 저장된다. 저장에 실패하면 이전 값으로 되돌리고 오류를 MUST 안내한다.

#### Scenario: 화면 설정에서 변경
- **WHEN** 화면 설정에서 주 시작 요일을 월요일로 바꾼 뒤 달력으로 돌아간다
- **THEN** 달력의 요일 머리글과 격자가 월요일 시작으로 표시된다

#### Scenario: 저장 실패
- **WHEN** 주 시작 요일을 바꿨으나 저장소 쓰기가 실패한다
- **THEN** 선택이 이전 값으로 되돌아가고 저장하지 못했다는 안내가 표시된다
