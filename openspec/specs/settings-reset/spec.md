# settings-reset Specification

## Purpose

근무 패턴, 화면 설정, 앱 전체 데이터를 사용자가 확인 후 처음 상태로 되돌릴 수 있게 한다.

## Requirements

### Requirement: 초기화 화면
설정 목록의 "초기화" 화면은 전체 초기화 하나만 SHALL 제공한다. 근무 패턴 초기화와 화면 설정 초기화는 이 화면에 두어서는 MUST NOT 되며, 각각 근무 패턴 설정 화면과 화면 설정 화면에서 제공된다.

#### Scenario: 확인 취소
- **WHEN** 전체 초기화를 누르고 확인 창에서 취소한다
- **THEN** 아무것도 지워지지 않고 초기화 화면에 머무른다

#### Scenario: 초기화 화면 구성
- **WHEN** 설정 목록에서 "초기화"를 연다
- **THEN** 전체 초기화 버튼만 보이고 근무 패턴·화면 설정 초기화 버튼은 없다

### Requirement: 근무 패턴 초기화
근무 패턴 초기화는 저장된 패턴이 있을 때 근무 패턴 설정 화면 아래에 SHALL 제공된다. 실행하면 반복 패턴과 기준일만 지우고 화면 설정·이름·날짜 세부 내용은 유지하며, 근무 패턴 등록 안내 화면이 표시된다. 저장된 패턴이 없는 최초 등록 화면에는 이 버튼을 두어서는 MUST NOT 된다.

#### Scenario: 패턴 초기화
- **WHEN** 근무 패턴 설정 화면 아래의 근무 패턴 초기화를 누르고 확인한다
- **THEN** 근무 패턴 등록 안내 화면이 표시되고, 새 패턴을 저장하면 기존 테마·주 시작 요일·이름·세부 내용이 그대로 적용된다

#### Scenario: 편집 중 초기화
- **WHEN** 근무 패턴 설정 화면에서 패턴을 고친 뒤 저장하지 않고 근무 패턴 초기화를 확인한다
- **THEN** 고치던 내용과 저장된 패턴이 함께 지워지고 근무 패턴 등록 안내 화면이 표시된다

#### Scenario: 최초 등록
- **WHEN** 저장된 패턴 없이 근무 패턴을 처음 등록한다
- **THEN** 등록 화면에 근무 패턴 초기화 버튼이 보이지 않는다

### Requirement: 화면 설정 초기화
화면 설정 초기화는 화면 설정 화면 아래에 SHALL 제공된다. 실행하면 테마를 인디고, 주 시작 요일을 일요일로 되돌리며 다른 데이터는 유지하고, 화면 설정 화면에 머무른다.

#### Scenario: 화면 설정 초기화
- **WHEN** 딥 틸·월요일 시작 상태에서 화면 설정 화면 아래의 화면 설정 초기화를 확인한다
- **THEN** 화면 설정 화면에 머무른 채 테마가 인디고, 주 시작 요일이 일요일로 바뀌고 패턴·이름·세부 내용은 그대로이다

### Requirement: 전체 초기화
전체 초기화는 설정과 날짜 세부 내용을 포함한 턴캘의 모든 로컬 저장 데이터를 SHALL 삭제하고 처음 실행한 상태로 돌아간다.

#### Scenario: 전체 초기화
- **WHEN** 전체 초기화를 확인한다
- **THEN** 초기 안내 화면이 인디고 테마로 표시되고, 앱을 다시 열어도 저장된 데이터가 없다

### Requirement: 초기화 실패 처리
초기화 중 저장소 쓰기·삭제가 실패하면 시스템은 데이터와 화면 상태를 바꾸지 않고 초기화를 실행한 화면에서 오류를 SHALL 안내한다.

#### Scenario: 삭제 실패
- **WHEN** 전체 초기화 중 저장소 삭제가 실패한다
- **THEN** 초기화 화면에 머무르며 초기화하지 못했다는 안내가 표시된다

#### Scenario: 화면 설정 초기화 실패
- **WHEN** 화면 설정 초기화 중 저장소 쓰기가 실패한다
- **THEN** 화면 설정 화면에 머무르며 테마·주 시작 요일은 이전 값이고 초기화하지 못했다는 안내가 표시된다

### Requirement: 초기화 확인
모든 초기화는 무엇이 지워지는지와 되돌릴 수 없음을 알리는 확인을 거쳐야만 SHALL 실행된다. 확인 창에서 취소하거나 뒤로가기를 누르면 아무것도 지워져서는 MUST NOT 된다.

#### Scenario: 근무 패턴 초기화 취소
- **WHEN** 근무 패턴 설정 화면에서 근무 패턴 초기화를 누르고 확인 창에서 취소한다
- **THEN** 패턴과 편집 내용이 그대로이고 근무 패턴 설정 화면에 머무른다

#### Scenario: 확인 창에서 뒤로가기
- **WHEN** 화면 설정 초기화 확인 창이 열린 상태에서 뒤로가기를 누른다
- **THEN** 확인 창만 닫히고 화면 설정은 그대로이다
