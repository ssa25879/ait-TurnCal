# settings-reset Specification

## Purpose

근무 패턴, 화면 설정, 앱 전체 데이터를 사용자가 확인 후 처음 상태로 되돌릴 수 있게 한다.

## Requirements

### Requirement: 초기화 화면
설정 목록의 "초기화" 화면은 근무 패턴 초기화, 화면 설정 초기화, 전체 초기화 세 가지를 SHALL 제공한다. 각 초기화는 무엇이 지워지는지와 되돌릴 수 없음을 알리는 확인을 거쳐야만 실행된다(MUST).

#### Scenario: 확인 취소
- **WHEN** 전체 초기화를 누르고 확인 창에서 취소한다
- **THEN** 아무것도 지워지지 않고 초기화 화면에 머무른다

### Requirement: 근무 패턴 초기화
근무 패턴 초기화는 반복 패턴과 기준일만 SHALL 지우고, 화면 설정·이름·날짜 세부 내용은 유지한다. 실행 후에는 근무 패턴 등록 안내 화면이 표시된다.

#### Scenario: 패턴 초기화
- **WHEN** 근무 패턴 초기화를 확인한다
- **THEN** 근무 패턴 등록 안내 화면이 표시되고, 새 패턴을 저장하면 기존 테마·주 시작 요일·이름·세부 내용이 그대로 적용된다

### Requirement: 화면 설정 초기화
화면 설정 초기화는 테마를 인디고, 주 시작 요일을 일요일로 SHALL 되돌리며 다른 데이터는 유지한다.

#### Scenario: 화면 설정 초기화
- **WHEN** 딥 틸·월요일 시작 상태에서 화면 설정 초기화를 확인한다
- **THEN** 테마가 인디고, 주 시작 요일이 일요일로 바뀌고 패턴·이름·세부 내용은 그대로이다

### Requirement: 전체 초기화
전체 초기화는 설정과 날짜 세부 내용을 포함한 턴캘의 모든 로컬 저장 데이터를 SHALL 삭제하고 처음 실행한 상태로 돌아간다.

#### Scenario: 전체 초기화
- **WHEN** 전체 초기화를 확인한다
- **THEN** 초기 안내 화면이 인디고 테마로 표시되고, 앱을 다시 열어도 저장된 데이터가 없다

### Requirement: 초기화 실패 처리
초기화 중 저장소 쓰기·삭제가 실패하면 시스템은 화면 상태를 바꾸지 않고 오류를 SHALL 안내한다.

#### Scenario: 삭제 실패
- **WHEN** 전체 초기화 중 저장소 삭제가 실패한다
- **THEN** 초기화 화면에 머무르며 초기화하지 못했다는 안내가 표시된다
