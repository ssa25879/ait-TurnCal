# user-identity Specification

## Purpose

앱인토스가 발급하는 비게임 미니앱용 사용자 식별키를 앱 시작 시 받아 기기에 저장해, 출시 가이드의 사용자 식별키 발급 기준을 지키면서도 앱 시작과 사용에는 영향을 주지 않게 한다.

## Requirements

### Requirement: 시작 시 식별키 발급과 저장
앱은 실행될 때마다 앱인토스 사용자 식별키 발급(비게임용)을 한 번 SHALL 요청하고, 받은 식별키를 기기 로컬 저장소 키 `turncal.user`에 `version`을 포함한 JSON으로 저장한다. 저장된 값과 같으면 다시 쓰지 않는다.

#### Scenario: 첫 실행
- **WHEN** 식별키를 지원하는 토스 앱에서 턴캘을 처음 연다
- **THEN** `turncal.user`에 받은 식별키가 저장된다

#### Scenario: 같은 식별키
- **WHEN** 이미 같은 식별키가 저장된 상태로 앱을 다시 연다
- **THEN** `turncal.user`를 다시 쓰지 않는다

### Requirement: 식별키 실패 허용
식별키 발급이 지원되지 않거나(낮은 토스 앱 버전 등), 오류가 나거나, 저장에 실패해도 앱은 SHALL 평소처럼 시작·동작해야 하며 사용자에게 오류를 표시해서는 MUST NOT 된다. 식별키 요청은 첫 화면 표시를 기다리게 해서도 MUST NOT 된다.

#### Scenario: 미지원 환경
- **WHEN** 식별키 발급을 지원하지 않는 환경에서 앱을 연다
- **THEN** 첫 화면과 모든 기능이 평소대로 동작하고 오류 안내가 없으며 `turncal.user`는 쓰이지 않는다

#### Scenario: 발급 오류
- **WHEN** 식별키 발급 요청이 오류로 끝난다
- **THEN** 앱은 평소대로 동작하고 기존 `turncal.user` 값은 그대로이다

### Requirement: 식별키 비노출·비전송
식별키는 화면이나 접근성 이름에 표시해서는 MUST NOT 되며, 네트워크로 전송해서도 MUST NOT 된다. 식별키는 설정·세부 내용의 저장 방식이나 검증에 SHALL 영향을 주지 않는다.

#### Scenario: 화면
- **WHEN** 어떤 화면을 연다
- **THEN** 식별키 값이 보이지 않는다

#### Scenario: 기존 데이터
- **WHEN** 식별키를 받지 못한 상태로 기존 설정·세부 내용이 저장된 앱을 연다
- **THEN** 설정과 세부 내용이 평소대로 표시된다
