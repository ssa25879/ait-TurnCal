# in-app-ads Specification

## Purpose

턴캘의 인앱 광고 노출 규칙을 정의한다. 달력 화면 하단에 토스 애즈 배너 하나만 두고, 앱인토스 출시 가이드와 토스 애즈 SSP 정책을 지키며 근무 확인 흐름을 방해하지 않는다.

## Requirements

### Requirement: 달력 하단 배너 위치
달력 화면은 달력 격자와 [설정] 버튼보다 아래, 화면의 맨 끝에 배너 광고 1개를 SHALL 표시한다. 배너와 [설정] 버튼 사이에는 버튼과 붙어 보이지 않도록 간격을 두어야 하며(MUST), 배너는 화면 전체 너비로 표시된다. 한 화면에 배너를 2개 이상 두어서는 MUST NOT 된다.

#### Scenario: 배너 위치
- **WHEN** 광고를 지원하는 환경에서 달력 화면을 연다
- **THEN** 달력 격자와 [설정] 버튼 아래에 간격을 두고 배너 1개가 화면 전체 너비로 표시된다

#### Scenario: 콘텐츠 우선
- **WHEN** 달력 화면을 처음 연다
- **THEN** 달력 격자와 [설정] 버튼이 배너보다 위에 있어 배너를 지나치지 않고도 근무를 확인하고 설정에 들어갈 수 있다

### Requirement: 광고를 넣지 않는 화면
달력 화면 외의 화면(초기 안내, 근무 패턴 설정, 설정 목록, 화면 설정, 오류 안내)과 바텀시트·다이얼로그에는 광고를 표시해서는 MUST NOT 된다. 전면 광고와 리워드 광고는 표시하지 않는다.

#### Scenario: 설정 화면
- **WHEN** 설정 목록, 근무 패턴 설정, 화면 설정 중 어느 화면을 연다
- **THEN** 광고가 표시되지 않는다

#### Scenario: 진입 직후
- **WHEN** 미니앱을 처음 연다
- **THEN** 전면 광고나 광고 바텀시트가 나타나지 않는다

### Requirement: 배너 표시 형식
배너는 미니앱의 라이트 모드와 같도록 라이트 테마로 SHALL 표시되며, 기기 다크모드를 따라가서는 MUST NOT 된다. 광고의 "Ad" 표기·문구·디자인은 SDK가 제공하는 그대로 유지해야 한다(MUST).

#### Scenario: 기기 다크모드
- **WHEN** 기기가 다크모드인 상태로 달력 화면을 연다
- **THEN** 배너가 라이트 테마로 표시된다

### Requirement: 배너 숨김 조건
광고 기능을 지원하지 않는 환경이거나, 광고 초기화·렌더링에 실패했거나, 표시할 광고가 없으면 배너 영역을 SHALL 숨겨 빈 공간을 남기지 않는다. 이 경우에도 달력의 다른 기능은 정상 동작해야 한다(MUST).

#### Scenario: 미지원 환경
- **WHEN** 배너 광고를 지원하지 않는 토스 앱 버전에서 달력 화면을 연다
- **THEN** 배너 영역이 보이지 않고 달력·월 이동·설정 진입은 정상 동작한다

#### Scenario: 표시할 광고 없음
- **WHEN** 광고 요청 결과 표시할 광고가 없다
- **THEN** 배너 영역이 숨겨진다

#### Scenario: 렌더링 실패
- **WHEN** 배너 렌더링이 실패한다
- **THEN** 배너 영역이 숨겨지고 오류 안내는 표시되지 않는다

### Requirement: 배너 생명주기
광고 SDK는 앱 실행 중 한 번만 SHALL 초기화된다. 배너는 달력 화면이 표시될 때 부착되고 달력 화면을 떠날 때 제거되어야 하며(MUST), 앱이 광고 영역을 임의로 새로고침해서는 MUST NOT 된다.

#### Scenario: 화면 이동 반복
- **WHEN** 달력 → 설정 목록 → 달력으로 여러 번 오간다
- **THEN** SDK 초기화는 한 번만 일어나고, 달력에 돌아올 때마다 배너는 하나만 부착된다

### Requirement: 광고 ID 사용 규칙
개발·테스트 빌드는 토스 애즈 테스트 광고 ID만 SHALL 사용한다. 출시 빌드는 빌드 설정으로 주입된 실제 광고 그룹 ID를 사용하며, 실제 ID가 없으면 배너를 표시해서는 MUST NOT 된다.

#### Scenario: 개발 빌드
- **WHEN** 개발 서버나 테스트 빌드로 달력 화면을 연다
- **THEN** 테스트 광고 ID로 배너를 요청한다

#### Scenario: 실제 ID 없는 출시 빌드
- **WHEN** 실제 광고 그룹 ID 없이 출시 빌드를 만든다
- **THEN** 달력 화면에 배너가 표시되지 않는다
