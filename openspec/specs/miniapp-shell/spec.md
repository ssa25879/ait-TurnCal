# miniapp-shell Specification

## Purpose

턴캘이 앱인토스 비게임 미니앱으로서 지켜야 하는 셸 동작(내비게이션 바, 뒤로가기·종료, 테마, 안전 영역, 확대·축소, 바텀시트 정책)을 정의한다.

## Requirements

### Requirement: 앱인토스 내비게이션 바 사용
미니앱은 상단에 앱인토스 내비게이션 바를 SHALL 사용하며, 자체 상단 바나 자체 뒤로가기 버튼을 표시해서는 MUST NOT 된다. 파트너 자체 로고를 내비게이션 바에 추가해서는 MUST NOT 된다.

#### Scenario: 뒤로가기 버튼 중복 없음
- **WHEN** 어떤 화면이든 표시된다
- **THEN** 화면에 보이는 뒤로가기 버튼은 토스 내비게이션 바의 것 하나뿐이다

### Requirement: 최초 화면 뒤로가기 시 종료
최초 화면에서 뒤로가기(토스 내비게이션 바 또는 Android 시스템 백버튼)를 누르면 미니앱이 SHALL 종료된다. 최초 화면은 항상 달력이며(저장된 설정이 없거나 근무 패턴이 없어도 마찬가지) 별도의 초기 설정 화면은 없다.

#### Scenario: 달력에서 뒤로가기
- **WHEN** 저장된 설정이 있는 상태로 달력 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 패턴이 없는 달력에서 뒤로가기
- **WHEN** 근무 패턴을 초기화한 뒤 표시된 달력 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 첫 실행·전체 초기화 뒤 달력에서 뒤로가기
- **WHEN** 저장된 설정이 없는 첫 실행이거나 전체 초기화를 한 뒤(앱을 다시 연 경우 포함) 빈 달력에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 초기 설정 흐름에서 뒤로가기
- **WHEN** 저장된 설정이 없는 첫 실행의 빈 달력에서 [근무 패턴 등록하기]로 연 첫 설정 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료되지 않고 빈 달력으로 돌아가며, 빈 달력에서 한 번 더 누르면 종료된다

#### Scenario: 패턴이 없는 상태의 설정 계층
- **WHEN** 패턴이 없는 달력에서 [근무 패턴 등록하기]로 근무 패턴 설정 화면을 연 뒤 변경 없이 뒤로가기를 누른다
- **THEN** 설정 계층 규칙에 따라 설정 목록이 아니라 달력으로 돌아가며 미니앱은 종료되지 않는다

### Requirement: 설정 화면 뒤로가기
저장된 설정이 있는 상태에서 뒤로가기를 누르면 설정 계층을 한 단계씩 SHALL 올라간다: 이름·근무 패턴 설정·근무 유형·화면 설정·캘린더 알림·초기화 화면은 설정 목록으로, 설정 목록은 달력으로 돌아간다. 근무 패턴 설정, 이름, 근무 유형 화면에 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인한다.

#### Scenario: 변경 없음
- **WHEN** 변경 없이 근무 패턴 설정 화면에서 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아간다

#### Scenario: 화면 설정에서 뒤로가기
- **WHEN** 화면 설정에서 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아가며 이미 바꾼 테마·주 시작 요일은 저장된 상태로 유지된다

#### Scenario: 캘린더 알림에서 뒤로가기
- **WHEN** 캘린더 알림 화면에서 시각을 고른 뒤 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아가며 고른 시각은 저장된 상태로 유지된다

#### Scenario: 초기화 화면에서 뒤로가기
- **WHEN** 초기화 화면에서 아무것도 실행하지 않고 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아가고 데이터는 그대로이다

#### Scenario: 설정 목록에서 뒤로가기
- **WHEN** 설정 목록 화면에서 뒤로가기를 누른다
- **THEN** 달력 화면으로 돌아간다

#### Scenario: 변경 폐기 확인
- **WHEN** 근무 패턴 설정, 이름, 근무 유형 화면에 저장하지 않은 변경이 있는 상태로 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 설정 목록 화면으로 돌아가며 저장된 설정은 그대로이다

#### Scenario: 폐기 취소
- **WHEN** 폐기 확인에서 취소를 누른다
- **THEN** 편집 중이던 화면에 머무르고 편집 내용이 유지된다

#### Scenario: Android 시스템 백버튼
- **WHEN** Android 시스템 백버튼을 누른다
- **THEN** 토스 내비게이션 바 뒤로가기와 같은 규칙으로 동작한다

#### Scenario: 근무 유형 화면에서 뒤로가기
- **WHEN** 변경 없이 근무 유형 화면에서 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아간다

### Requirement: 오버레이 우선 닫기
바텀시트나 다이얼로그가 열려 있는 상태에서 뒤로가기(토스 내비게이션 바 또는 Android 시스템 백버튼)를 누르면 시스템은 가장 최근에 열린 오버레이만 SHALL 닫는다. 이때 화면 이동이나 미니앱 종료가 일어나서는 MUST NOT 된다.

#### Scenario: 바텀시트 열린 상태
- **WHEN** 설정 화면에서 패턴 항목 바텀시트가 열린 상태로 뒤로가기를 누른다
- **THEN** 바텀시트만 닫히고 설정 화면과 편집 내용은 그대로이다

#### Scenario: 폐기 확인 다이얼로그 열린 상태
- **WHEN** 변경 폐기 확인 다이얼로그가 열린 상태로 뒤로가기를 누른다
- **THEN** 다이얼로그만 닫히고 설정 화면에 머무르며 편집 내용이 유지된다

#### Scenario: 최초 화면의 오버레이
- **WHEN** 최초 화면에서 오버레이가 열린 상태로 뒤로가기를 누른다
- **THEN** 오버레이만 닫히고 미니앱은 종료되지 않는다

### Requirement: 라이트 모드 전용
미니앱 화면은 기기 테마와 무관하게 라이트 모드로 SHALL 표시된다.

#### Scenario: 기기 다크 모드
- **WHEN** 기기가 다크 모드인 상태로 미니앱을 연다
- **THEN** 미니앱 화면은 라이트 모드로 표시된다

### Requirement: 안전 영역 적용
콘텐츠는 상단 내비게이션 바와 하단 홈 인디케이터 영역에 가려지지 않도록 플랫폼이 제공하는 안전 영역 여백을 SHALL 적용하며, 여백 변경 시 다시 반영한다.

#### Scenario: 하단 홈 인디케이터
- **WHEN** 홈 인디케이터가 있는 iPhone에서 달력을 끝까지 스크롤한다
- **THEN** 마지막 행과 버튼이 홈 인디케이터에 가려지지 않는다

### Requirement: 확대·축소 비활성화
제스처 기반 확대·축소는 SHALL 비활성화된다.

#### Scenario: 핀치 줌
- **WHEN** 사용자가 화면에서 핀치 줌을 한다
- **THEN** 화면이 확대되지 않는다

### Requirement: 바텀시트 자동 표시 금지
미니앱은 진입 시나 화면 전환 시 바텀시트를 자동으로 띄워서는 MUST NOT 된다. 바텀시트는 사용자의 명시적 조작에 대한 응답으로만 표시된다.

#### Scenario: 진입
- **WHEN** 미니앱을 연다
- **THEN** 바텀시트가 자동으로 나타나지 않는다

### Requirement: 반응 속도
스크롤, 터치, 화면 전환 반응은 2초 이상 지연되어서는 MUST NOT 된다.

#### Scenario: 월 이동 반응
- **WHEN** 실기기에서 다음 달 버튼을 누른다
- **THEN** 2초 안에 다음 달 달력이 표시된다

### Requirement: 날짜 화면 뒤로가기
날짜 화면에서 뒤로가기를 누르면 달력으로, 세부 내용 편집 화면에서 뒤로가기를 누르면 날짜 화면으로 SHALL 돌아간다. 편집 화면에 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인한다.

#### Scenario: 날짜 화면
- **WHEN** 날짜 화면에서 뒤로가기를 누른다
- **THEN** 달력 화면으로 돌아가고 보던 달이 유지된다

#### Scenario: 편집 중 뒤로가기
- **WHEN** 세부 내용 편집 화면에서 이름을 바꾼 뒤 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 날짜 화면으로 돌아간다

### Requirement: 달력 바로가기로 연 화면의 뒤로가기
달력의 [근무 패턴 수정]·[이름 수정]·[근무 패턴 등록하기]로 연 화면에서 뒤로가기(토스 내비게이션 바 또는 Android 시스템 백버튼)를 누르면 설정 목록이 아니라 **달력**으로 SHALL 돌아가며 미니앱은 종료되지 않는다. 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인하고, 폐기를 확인하면 달력으로 돌아가며 취소하면 편집 중인 화면에 그대로 머문다. 설정 목록을 거쳐 연 화면의 뒤로가기 계층(상세 → 설정 목록 → 달력)은 바뀌지 않는다.

#### Scenario: 변경 없이 뒤로가기
- **WHEN** 달력의 [이름 수정]으로 이름 화면을 연 뒤 변경 없이 뒤로가기를 누른다
- **THEN** 달력이 표시되고 미니앱은 종료되지 않는다

#### Scenario: 변경 폐기 확인 후 달력 복귀
- **WHEN** [근무 패턴 수정]으로 연 화면에서 패턴을 고친 뒤 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 달력이 표시되며 저장된 패턴은 그대로이다

#### Scenario: 폐기 취소
- **WHEN** 위 확인 창에서 계속 편집하기를 누른다
- **THEN** 편집 중이던 화면과 입력 내용이 그대로 남는다

#### Scenario: 설정 목록 경로는 그대로
- **WHEN** [설정] → 설정 목록 → 이름 화면을 연 뒤 뒤로가기를 누른다
- **THEN** 설정 목록으로 돌아가고 한 번 더 누르면 달력으로 돌아간다

#### Scenario: 바로가기 뒤 달력에서 종료
- **WHEN** 바로가기로 연 화면에서 뒤로가기로 달력에 돌아온 뒤 한 번 더 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

### Requirement: 설정 진입 내비게이션 바 기능 버튼
달력 화면에서는 토스 내비게이션 바에 "설정" 기능 버튼을 SHALL 1개 표시하고, 누르면 설정 목록이 열려야 한다. 이 버튼은 달력 화면에서만 보이며 설정 목록·근무 패턴 설정·이름·화면 설정·초기화·날짜·세부 내용 화면에서는 표시되지 않아야 한다(MUST). 미니앱 기능 버튼은 최대 1개만 표시한다. 설정 목록을 연 뒤의 뒤로가기 계층(설정 목록 → 달력)과 최초 화면 뒤로가기 종료는 바뀌지 않는다. 기능 버튼을 등록하지 못하는 환경에서는 달력 하단에 [설정] 버튼을 대체 수단으로 SHALL 표시하고, 기능 버튼이 등록된 환경에서는 하단 [설정] 버튼을 표시해서는 MUST NOT 된다.

#### Scenario: 달력에서 설정 열기
- **WHEN** 달력 화면에서 내비게이션 바의 "설정" 기능 버튼을 누른다
- **THEN** 설정 목록이 열리고 항목 4개(이름, 근무 패턴, 화면 설정, 초기화)가 표시된다

#### Scenario: 달력이 아닌 화면
- **WHEN** 설정 목록, 날짜 화면, 근무 패턴 설정, 이름 화면 중 하나를 연다
- **THEN** 내비게이션 바에 "설정" 기능 버튼이 표시되지 않는다

#### Scenario: 설정에서 돌아오기
- **WHEN** 설정 목록에서 뒤로가기를 누른다
- **THEN** 달력으로 돌아가고 내비게이션 바에 "설정" 기능 버튼이 다시 표시된다

#### Scenario: 기능 버튼을 쓸 수 없는 환경
- **WHEN** 기능 버튼을 등록할 수 없는 환경에서 달력을 연다
- **THEN** 달력 하단에 [설정] 버튼이 표시되고 누르면 설정 목록이 열린다

#### Scenario: 기능 버튼이 있는 환경
- **WHEN** 기능 버튼이 등록된 환경에서 달력을 본다
- **THEN** 달력 하단에는 [설정] 버튼이 없고 [근무 패턴 수정]·[이름 수정]만 있다
