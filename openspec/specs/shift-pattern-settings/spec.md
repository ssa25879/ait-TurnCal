# shift-pattern-settings Specification

## Purpose

사용자가 반복 근무 패턴을 만들고 수정하며, 오늘 위치 선택으로 기준일을 지정해 설정을 확정하는 편집 흐름을 정의한다.

## Requirements

### Requirement: 초기 설정 안내
저장된 설정이 없으면 시스템은 첫 화면으로 패턴 등록 안내를 일반 화면으로 SHALL 표시하고, 패턴 등록 CTA로 설정 화면에 진입시킨다. 안내를 바텀시트로 자동 표시해서는 MUST NOT 된다.

#### Scenario: 최초 실행
- **WHEN** 저장된 설정 없이 앱을 처음 연다
- **THEN** 패턴 등록 안내 화면과 [패턴 등록하기] 버튼이 표시되고 바텀시트는 뜨지 않는다

#### Scenario: 설정 화면 진입
- **WHEN** 사용자가 [패턴 등록하기]를 누른다
- **THEN** 패턴 설정 화면이 열린다

### Requirement: 근무 유형 추가
설정 화면은 6개 근무 유형 버튼을 SHALL 제공하며, 버튼을 누르면 해당 유형이 편집 중 패턴의 끝에 추가된다.

#### Scenario: 유형 추가
- **WHEN** 편집 중 패턴이 `[주간]`이고 사용자가 [야간]을 누른다
- **THEN** 편집 중 패턴은 `[주간, 야간]`이 된다

#### Scenario: 최대 길이 도달
- **WHEN** 편집 중 패턴이 56개이다
- **THEN** 유형 추가가 비활성화되고 최대 길이에 도달했다는 사유가 표시된다

### Requirement: 임의 위치 항목 편집
사용자는 편집 중 패턴의 어느 위치 항목이든 선택해 유형을 변경하거나 삭제할 수 SHALL 있다. 변경·삭제 선택 UI는 사용자가 항목을 탭했을 때만 표시된다.

#### Scenario: 가운데 항목 유형 변경
- **WHEN** 편집 중 패턴이 `[주간, 주간, 야간]`이고 사용자가 두 번째 항목을 비번으로 바꾼다
- **THEN** 편집 중 패턴은 `[주간, 비번, 야간]`이 된다

#### Scenario: 가운데 항목 삭제
- **WHEN** 편집 중 패턴이 `[주간, 주간, 야간]`이고 사용자가 두 번째 항목을 삭제한다
- **THEN** 편집 중 패턴은 `[주간, 야간]`이 된다

### Requirement: 오늘 위치 선택
설정 화면은 편집 중 패턴의 칸 중 오늘에 해당하는 칸을 선택하게 SHALL 하며, 선택 결과로 기준일을 계산한다. 저장된 설정이 있으면 저장된 기준일로 계산한 오늘 위치가 미리 선택되어 있어야 한다(MUST).

#### Scenario: 저장된 설정으로 진입
- **WHEN** 저장된 기준일이 `2026-10-13`, 패턴 길이 6이고 오늘이 `2026-10-15`인 상태에서 설정 화면을 연다
- **THEN** 세 번째 칸(인덱스 2)이 오늘 위치로 미리 선택되어 있다

#### Scenario: 패턴 길이 변경 후 보정
- **WHEN** 오늘 위치가 인덱스 4로 선택된 상태에서 패턴 길이가 3으로 줄어든다
- **THEN** 오늘 위치는 인덱스 1(4 mod 3)로 보정되어 선택된다

#### Scenario: 오늘 위치 미선택
- **WHEN** 새 패턴을 만들고 오늘 위치를 아직 선택하지 않았다
- **THEN** [저장]이 비활성화되고 오늘 위치를 선택하라는 사유가 표시된다

### Requirement: 기준일 직접 지정
설정 화면은 보조 수단으로 패턴 첫째 날을 날짜로 직접 지정하는 방법을 SHALL 제공한다. 유효하지 않은 날짜는 MUST 거부된다.

#### Scenario: 날짜로 지정
- **WHEN** 사용자가 날짜 직접 지정에서 `2026-10-13`을 고른다
- **THEN** 기준일이 `2026-10-13`으로 설정되고 오늘 위치 선택이 그에 맞게 갱신된다

#### Scenario: 범위 밖 날짜
- **WHEN** 사용자가 지원 범위 밖 날짜를 입력한다
- **THEN** 저장할 수 없고 오류 사유가 표시된다

### Requirement: 편집 내용 확정
설정 화면의 변경은 임시 상태로 유지되며 [저장]을 눌렀을 때만 저장소와 달력에 SHALL 반영된다. 패턴이 비었거나, 56개를 넘거나, 오늘 위치가 없으면 [저장]은 MUST 비활성화된다. 저장된 패턴이 있고 편집 내용이 저장된 패턴과 다르면 설정 화면 안에서 적용 범위(오늘부터 적용 / 전체 기간에 적용)를 고르게 하며, 적용 범위는 바텀시트나 다이얼로그가 아닌 설정 화면 안의 선택으로 제공되어야 한다(MUST). 저장 성공 후에는 선택한 적용 범위에 따라 계산된 근무가 달력에 즉시 표시된다.

#### Scenario: 저장 성공
- **WHEN** 유효한 패턴과 오늘 위치로 [저장]을 누르고 저장에 성공한다
- **THEN** 달력 화면으로 돌아가고 선택한 적용 범위로 계산된 근무가 즉시 표시된다

#### Scenario: 저장 실패
- **WHEN** [저장]을 눌렀으나 저장소 쓰기가 실패한다
- **THEN** 설정 화면에 머무르며 편집 내용과 선택한 적용 범위가 유지되고 오류가 안내된다

#### Scenario: 저장 전 달력 불변
- **WHEN** 사용자가 패턴을 편집했지만 [저장]하지 않았다
- **THEN** 달력에 표시되는 근무는 바뀌지 않는다

#### Scenario: 적용 범위 선택
- **WHEN** 저장된 패턴이 있는 상태에서 근무 순서를 고친다
- **THEN** 같은 화면에 "오늘부터 적용(지난 날짜는 이전 패턴 유지)"과 "전체 기간에 적용(지난 날짜도 새 패턴으로 계산)" 선택이 표시되고 앞의 것이 선택되어 있다

#### Scenario: 적용 범위 선택은 오버레이가 아님
- **WHEN** 적용 범위 선택이 표시된 상태에서 뒤로가기를 누른다
- **THEN** 별도 창이 닫히는 동작 없이 변경 폐기 확인 규칙을 따른다

### Requirement: 데이터 유지 범위 안내
설정 화면은 앱을 삭제하면 저장된 설정이 삭제되며 기기 간 자동 동기화가 없다는 사실을 SHALL 안내한다.

#### Scenario: 안내 표시
- **WHEN** 사용자가 설정 화면을 연다
- **THEN** 앱 삭제 시 데이터 삭제 및 동기화 미지원 안내 문구가 표시된다
