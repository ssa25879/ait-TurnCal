# shift-calendar Specification

## Purpose

저장된 근무 패턴으로 계산한 근무 유형을 월간 달력에 표시하고, 월 이동·오늘 강조·주 시작 요일 설정을 제공한다.

## Requirements

### Requirement: 월간 달력 격자
달력은 어느 월이든 6행 7열(42칸) 고정 격자로 SHALL 표시하며, 첫 칸은 해당 월 1일이 속한 주의 주 시작 요일이다.

#### Scenario: 일요일 시작
- **WHEN** 주 시작 요일이 일요일이고 2026년 10월을 표시한다
- **THEN** 첫 칸은 `2026-09-27`, 마지막 칸은 `2026-11-07`이다

#### Scenario: 월요일 시작
- **WHEN** 주 시작 요일이 월요일이고 2026년 10월을 표시한다
- **THEN** 첫 칸은 `2026-09-28`, 마지막 칸은 `2026-11-08`이다

#### Scenario: 1일이 주 시작 요일인 달
- **WHEN** 주 시작 요일이 일요일이고 2026년 2월을 표시한다
- **THEN** 첫 칸은 `2026-02-01`이다

### Requirement: 근무 유형 표시
달력의 모든 칸은 날짜와 그 날짜의 근무 유형을 SHALL 표시한다. 근무 유형은 색상과 한 글자 약어로 함께 구별되어야 하며 색상만으로 구별해서는 MUST NOT 된다. 표시 월이 아닌 인접 월 칸은 흐리게 표시한다.

#### Scenario: 약어 표시
- **WHEN** 어떤 날짜의 근무가 야간이다
- **THEN** 해당 칸에 "야" 문자가 근무 색상과 함께 표시된다

#### Scenario: 인접 월 칸
- **WHEN** 2026년 10월 달력의 `2026-09-27` 칸을 본다
- **THEN** 날짜와 근무 유형이 흐리게 표시된다

### Requirement: 월 이동
사용자는 이전 달·다음 달로 이동하고 오늘이 속한 달로 바로 돌아올 수 SHALL 있다. 연도 경계를 넘는 이동이 정확해야 한다(MUST).

#### Scenario: 연말 이동
- **WHEN** 2026년 12월에서 다음 달로 이동한다
- **THEN** 2027년 1월이 표시되고 근무가 계산되어 있다

#### Scenario: 오늘로 이동
- **WHEN** 다른 달을 보다가 [오늘]을 누른다
- **THEN** 오늘이 속한 달이 표시된다

### Requirement: 오늘 강조
달력은 기기 로컬 기준 오늘 날짜 칸을 다른 칸과 구별되게 SHALL 강조한다. 앱이 다시 화면에 보일 때 날짜가 바뀌었으면 강조가 새 오늘로 MUST 이동한다.

#### Scenario: 오늘 칸 강조
- **WHEN** 오늘이 `2026-10-15`이고 2026년 10월을 본다
- **THEN** `2026-10-15` 칸이 강조된다

#### Scenario: 자정 경과 후 복귀
- **WHEN** 앱을 화면에 띄운 채 자정을 넘긴 뒤 앱이 다시 화면에 보인다
- **THEN** 새 날짜 칸이 강조된다

### Requirement: 주 시작 요일 설정
사용자는 주 시작 요일을 일요일 또는 월요일로 선택할 수 SHALL 있으며 기본값은 일요일이다. 변경은 [저장] 없이 즉시 저장되고 달력에 반영된다.

#### Scenario: 월요일로 변경
- **WHEN** 사용자가 주 시작 요일을 월요일로 바꾼다
- **THEN** 달력의 요일 머리글과 격자가 월요일 시작으로 즉시 재배치된다

#### Scenario: 재실행 후 유지
- **WHEN** 주 시작 요일을 월요일로 바꾼 뒤 앱을 다시 연다
- **THEN** 달력은 월요일 시작으로 표시된다
