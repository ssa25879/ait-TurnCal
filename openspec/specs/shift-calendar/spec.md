# shift-calendar Specification

## Purpose

저장된 근무 패턴으로 계산한 근무 유형을 월간 달력에 표시하고, 월 이동·오늘 강조·주 시작 요일 설정을 제공한다.

## Requirements

### Requirement: 월간 달력 격자
달력은 어느 월이든 6행 7열(42칸) 고정 격자로 SHALL 표시하며, 첫 칸은 해당 월 1일이 속한 주의 주 시작 요일이다.

#### Scenario: 일요일 시작
- **WHEN** 주 시작 요일이 일요일이고 2026년 10월을 표시한다
- **THEN** 첫 칸은 `2026-09-27`, 마지막 칸은 `2026-11-07`이다

#### Scenario: 월요일 시작
- **WHEN** 주 시작 요일이 월요일이고 2026년 10월을 표시한다
- **THEN** 첫 칸은 `2026-09-28`, 마지막 칸은 `2026-11-08`이다

#### Scenario: 1일이 주 시작 요일인 달
- **WHEN** 주 시작 요일이 일요일이고 2026년 2월을 표시한다
- **THEN** 첫 칸은 `2026-02-01`이다

### Requirement: 근무 유형 표시
달력의 모든 칸은 날짜와 그 날짜의 근무 유형을 SHALL 표시하며, 근무 유형은 날짜 세부 내용으로 바뀐 근무가 있으면 그것을, 없으면 반복 패턴의 근무를 쓴다. 근무 유형은 색상과 한 글자 약어로 함께 구별되어야 하며 색상만으로 구별해서는 MUST NOT 된다. 표시 월이 아닌 인접 월 칸은 흐리게 표시한다. 모든 칸은 누를 수 있으며 누르면 그 날짜 화면이 열린다.

#### Scenario: 약어 표시
- **WHEN** 어떤 날짜의 근무가 야간이다
- **THEN** 해당 칸에 "야" 문자가 근무 색상과 함께 표시된다

#### Scenario: 인접 월 칸
- **WHEN** 2026년 10월 달력의 `2026-09-27` 칸을 본다
- **THEN** 날짜와 근무 유형이 흐리게 표시된다

#### Scenario: 바뀐 근무 반영
- **WHEN** 패턴상 야간인 날에 분류 "휴무" 세부 내용이 있다
- **THEN** 그 칸에 "휴"가 휴무 색상으로 표시된다

#### Scenario: 칸 누르기
- **WHEN** 달력의 아무 날짜 칸을 누른다
- **THEN** 그 날짜 화면이 열린다

### Requirement: 월 이동
사용자는 이전 달·다음 달로 이동하고 오늘이 속한 달로 바로 돌아올 수 SHALL 있다. 연도 경계를 넘는 이동이 정확해야 한다(MUST).

#### Scenario: 연말 이동
- **WHEN** 2026년 12월에서 다음 달로 이동한다
- **THEN** 2027년 1월이 표시되고 근무가 계산되어 있다

#### Scenario: 오늘로 이동
- **WHEN** 다른 달을 보다가 [오늘]을 누른다
- **THEN** 오늘이 속한 달이 표시된다

### Requirement: 오늘 강조
달력은 기기 로컬 기준 오늘 날짜 칸을 다른 칸과 구별되게 SHALL 강조한다. 앱이 다시 화면에 보일 때 날짜가 바뀌었으면 강조가 새 오늘로 MUST 이동한다.

#### Scenario: 오늘 칸 강조
- **WHEN** 오늘이 `2026-10-15`이고 2026년 10월을 본다
- **THEN** `2026-10-15` 칸이 강조된다

#### Scenario: 자정 경과 후 복귀
- **WHEN** 앱을 화면에 띄운 채 자정을 넘긴 뒤 앱이 다시 화면에 보인다
- **THEN** 새 날짜 칸이 강조된다

### Requirement: 주 시작 요일 설정
달력은 사용자가 화면 설정에서 고른 주 시작 요일(일요일 또는 월요일)을 SHALL 따르며 기본값은 일요일이다. 달력 화면에는 주 시작 요일 선택 UI를 두어서는 MUST NOT 되며, 변경은 화면 설정에서 즉시 저장되어 달력에 반영된다.

#### Scenario: 월요일로 변경
- **WHEN** 사용자가 화면 설정에서 주 시작 요일을 월요일로 바꾸고 달력으로 돌아온다
- **THEN** 달력의 요일 머리글과 격자가 월요일 시작으로 재배치되어 있다

#### Scenario: 재실행 후 유지
- **WHEN** 주 시작 요일을 월요일로 바꾼 뒤 앱을 다시 연다
- **THEN** 달력은 월요일 시작으로 표시된다

#### Scenario: 달력 화면에 선택 UI 없음
- **WHEN** 달력 화면을 연다
- **THEN** 주 시작 요일을 바꾸는 토글이나 선택지가 표시되지 않는다

### Requirement: 패턴이 없는 달력
현재 근무 패턴이 없는 경우(근무 패턴 초기화 뒤, 전체 초기화 뒤, 저장된 설정이 없는 첫 실행) 시스템은 별도의 등록 안내 화면 없이 **달력**을 SHALL 표시한다. 패턴이 없는 날짜의 칸은 근무 배지 없이 날짜(와 공휴일 표시)만 보여 주며 눌러서 날짜 화면을 열 수 있다. 달력 위쪽에는 "근무 패턴이 없어요"라는 안내와 [근무 패턴 등록하기] 버튼을 표시하고, 버튼은 근무 패턴 설정 화면을 연다. 날짜 세부 내용으로 근무를 바꿔 둔 날은 그 근무를 평소처럼 표시해야 한다(MUST). 날짜 화면은 패턴이 없는 날의 근무 줄에 "근무 패턴이 없어요"를 보여 주고 세부 내용 추가·수정은 그대로 제공한다.

#### Scenario: 패턴 초기화 직후
- **WHEN** 패턴 이력이 없는 상태에서 근무 패턴을 초기화한다
- **THEN** 달력 화면이 표시되고 모든 칸에 근무 배지가 없으며 "근무 패턴이 없어요" 안내와 [근무 패턴 등록하기] 버튼이 보인다

#### Scenario: 첫 실행
- **WHEN** 저장된 설정이 없는 상태로 앱을 처음 연다
- **THEN** 등록 안내 화면 없이 근무 배지가 없는 달력과 "근무 패턴이 없어요" 안내, [근무 패턴 등록하기] 버튼이 표시되고 저장소에는 아무것도 저장되지 않는다

#### Scenario: 이력이 남아 있는 달력
- **WHEN** 이력의 마지막 종료일이 `2026-10-13`이고 현재 패턴이 없는 상태로 2026년 10월 달력을 본다
- **THEN** `2026-10-12` 이전 칸은 이력의 패턴으로 근무가 표시되고 `2026-10-13` 이후 칸은 근무 배지가 없다

#### Scenario: 바뀐 근무는 유지
- **WHEN** 패턴이 없는 날짜에 분류 "휴무" 세부 내용이 있다
- **THEN** 그 칸에 "휴"가 휴무 색상으로 표시되고 "바뀐 근무" 표시가 보인다

#### Scenario: 등록하기 버튼
- **WHEN** [근무 패턴 등록하기]를 누른다
- **THEN** 근무 패턴 설정(첫 등록) 화면이 열리고, 저장하면 달력 화면에 새 패턴의 근무가 표시된다

#### Scenario: 날짜 화면
- **WHEN** 패턴이 없는 날짜의 칸을 누른다
- **THEN** 날짜 화면에 "근무 패턴이 없어요"가 표시되고 [세부 내용 추가]를 쓸 수 있다

### Requirement: 근무 패턴·이름 수정 바로가기
달력 화면은 달력 격자 아래에 [근무 패턴 수정]과 [이름 수정] 바로가기 버튼을 SHALL 표시하고, 누르면 설정 목록을 거치지 않고 각각 근무 패턴 설정 화면과 이름 화면을 연다. 근무 패턴이 없는 달력에서는 [근무 패턴 등록하기] 안내 카드가 그 역할을 하므로 [근무 패턴 수정]을 표시해서는 MUST NOT 되고 [이름 수정]만 표시한다. 버튼은 날짜 칸·오늘·내일 카드·월 이동·배너·[설정] 버튼의 동작과 배치를 가리거나 바꾸지 않아야 하며 360px 폭에서도 겹치거나 가로 스크롤을 만들지 않아야 한다. 설정 목록은 내비게이션 바의 "설정" 기능 버튼으로 열며, 기능 버튼을 쓸 수 없는 환경에서만 바로가기 줄 아래에 대체 [설정] 버튼을 표시한다.

#### Scenario: 근무 패턴 수정 바로가기
- **WHEN** 근무 패턴이 있는 달력에서 [근무 패턴 수정]을 누른다
- **THEN** 설정 목록이 아니라 근무 패턴 설정 화면이 바로 열리고 저장된 패턴이 불러와져 있다

#### Scenario: 이름 수정 바로가기
- **WHEN** 달력에서 [이름 수정]을 누른다
- **THEN** 설정 목록이 아니라 이름 화면이 바로 열리고 저장된 호칭·근무표 이름이 채워져 있다

#### Scenario: 패턴이 없는 달력
- **WHEN** 근무 패턴을 초기화한 뒤 달력을 연다
- **THEN** [근무 패턴 등록하기] 카드와 [이름 수정]은 보이고 [근무 패턴 수정]은 보이지 않는다

#### Scenario: 설정 버튼은 그대로
- **WHEN** 달력의 [설정](내비게이션 바 기능 버튼, 또는 기능 버튼을 쓸 수 없는 환경의 대체 하단 버튼)을 누른다
- **THEN** 설정 목록이 열리고 항목 4개가 그대로 표시된다

#### Scenario: 좁은 화면
- **WHEN** 360px 폭에서 근무표 이름이 최대 길이(20자)이고 호칭이 있는 달력을 본다
- **THEN** 바로가기 버튼이 다른 요소와 겹치지 않고 화면 안에 들어오며 가로 스크롤이 생기지 않는다
