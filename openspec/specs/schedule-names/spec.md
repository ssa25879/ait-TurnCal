# schedule-names Specification

## Purpose

사용자 호칭과 근무표 이름을 선택적으로 입력해, 달력이 누구의 어떤 근무표인지 한눈에 알아볼 수 있게 한다.

## Requirements

### Requirement: 이름 입력
설정 목록의 "이름" 화면에서 사용자 호칭(선택, 최대 10자)과 근무표 이름(선택, 최대 20자)을 SHALL 입력·수정할 수 있다. 앞뒤 공백은 제거해 저장하고, 비우면 입력하지 않은 것으로 처리한다. [저장]을 눌렀을 때만 반영된다.

#### Scenario: 이름 저장
- **WHEN** 호칭 "지수", 근무표 이름 "병동 3교대"를 입력하고 저장한다
- **THEN** 설정 목록으로 돌아가고 앱을 다시 열어도 두 값이 유지된다

#### Scenario: 길이 초과
- **WHEN** 근무표 이름에 21자를 입력한다
- **THEN** 저장할 수 없고 길이 제한 안내가 표시된다

### Requirement: 달력 상단 이름 표시
달력 화면 상단에 근무표 이름을 SHALL 표시하며, 입력하지 않았으면 "내 근무표"를 표시한다. 호칭이 있으면 "{호칭}님"을 함께 표시한다.

#### Scenario: 둘 다 입력
- **WHEN** 호칭 "지수", 근무표 이름 "병동 3교대"로 달력을 연다
- **THEN** 달력 상단에 "병동 3교대"와 "지수님"이 표시된다

#### Scenario: 입력 없음
- **WHEN** 이름을 입력하지 않은 채 달력을 연다
- **THEN** 달력 상단에 "내 근무표"만 표시된다

### Requirement: 달력 바로가기로 연 이름 화면의 저장
달력의 [이름 수정]으로 연 이름 화면에서 저장하면 설정 목록을 거치지 않았으므로 설정 목록이 아니라 **달력**으로 SHALL 돌아가며, 달력 상단에 바뀐 근무표 이름과 호칭이 즉시 표시되어야 한다. 입력 규칙(길이 제한·공백 제거·비우면 기본 표시)과 저장 실패 처리는 설정 목록 경로와 같다. 설정 목록의 "이름"으로 연 경우의 저장 후 이동은 바뀌지 않는다.

#### Scenario: 바로가기에서 저장
- **WHEN** 달력의 [이름 수정]에서 근무표 이름 "병동 3교대"를 입력하고 저장한다
- **THEN** 달력으로 돌아가고 상단에 "병동 3교대"가 표시되며 앱을 다시 열어도 유지된다

#### Scenario: 바로가기에서 길이 초과
- **WHEN** 달력의 [이름 수정]에서 근무표 이름에 21자를 입력한다
- **THEN** 저장할 수 없고 길이 제한 안내가 표시되며 화면은 이름 화면에 머문다

#### Scenario: 설정 목록 경로의 저장
- **WHEN** 설정 목록의 "이름"에서 저장한다
- **THEN** 지금처럼 설정 목록으로 돌아간다
