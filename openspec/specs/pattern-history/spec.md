# pattern-history Specification

## Purpose
근무제가 바뀌어도 이미 지난 날짜의 근무가 실제 근무와 달라지지 않도록, 패턴을 바꾼 날짜를 기준으로 날짜마다 그날 적용되던 패턴으로 근무를 계산하고, 사용자가 바꾼 기록을 확인하고 이전 패턴을 편집기에 다시 불러올 수 있게 한다.

## Requirements

### Requirement: 날짜별 적용 패턴
시스템은 각 날짜의 근무를 **그날 적용되던 패턴**으로 SHALL 계산한다. 달력 칸, 날짜 화면, 오늘·내일 요약은 같은 날짜에 대해 항상 같은 근무 유형을 보여야 한다(MUST). 패턴 이력이 없으면 저장된 패턴 하나로 모든 날짜를 계산한다. 날짜 세부 내용으로 근무를 바꾸는 규칙은 이전과 같고 이력의 영향을 받지 않는다.

#### Scenario: 이력이 없는 설정
- **WHEN** 이력 없이 저장된 패턴 하나로 앱을 연다
- **THEN** 모든 날짜가 그 패턴으로 계산된다

#### Scenario: 이력이 있는 설정
- **WHEN** 패턴 A(기준일 `2026-10-01`, `[주간, 야간, 휴무]`)가 `2026-10-13` 전까지 적용되었고 그날부터 패턴 B(기준일 `2026-10-13`, `[주간, 야간, 야간, 휴무]`)가 적용된다
- **THEN** `2026-10-10`은 패턴 A로 주간, `2026-10-12`는 패턴 A로 휴무, `2026-10-13`은 패턴 B로 주간, `2026-10-14`는 패턴 B로 야간이다

#### Scenario: 화면 간 일치
- **WHEN** 이력이 있는 설정에서 `2026-10-10`의 근무를 달력 칸, 날짜 화면, 요약 카드로 본다
- **THEN** 세 곳 모두 같은 근무 유형을 보여 준다

#### Scenario: 바뀐 근무 우선
- **WHEN** 이력상 패턴 A가 적용되는 날에 분류 "휴무" 세부 내용이 있다
- **THEN** 그날은 휴무로 표시되고 "바뀐 근무" 표시가 유지된다

### Requirement: 저장 시 적용 범위
저장된 패턴이 있는 상태에서 근무 패턴을 변경해 저장하면 사용자는 적용 범위를 SHALL 고를 수 있다. **오늘부터 적용**은 기본 선택이며, 저장한 오늘 이전 날짜는 변경 전 패턴으로 유지하고 오늘 이후 날짜는 새 패턴으로 계산한다. **전체 기간에 적용**은 이력을 모두 지우고 모든 날짜를 새 패턴으로 계산한다. 첫 등록(저장된 패턴이 없음)에는 적용 범위를 묻지 않고 새 패턴 하나로 모든 날짜를 계산한다(MUST).

#### Scenario: 오늘부터 적용
- **WHEN** 오늘이 `2026-10-13`이고 패턴 A(기준일 `2026-10-01`, `[주간, 야간, 휴무]`)가 저장되어 있으며, 오늘 위치를 첫째 칸으로 한 패턴 B(`[주간, 야간, 야간, 휴무]`)를 "오늘부터 적용"으로 저장한다
- **THEN** `2026-10-10`은 주간(패턴 A), `2026-10-12`는 휴무(패턴 A), `2026-10-13`은 주간(패턴 B), `2026-10-14`는 야간(패턴 B)이고 패턴 이력에 패턴 A가 `2026-10-13` 전까지 적용된 기록으로 남는다

#### Scenario: 전체 기간에 적용
- **WHEN** 같은 상황에서 패턴 B를 "전체 기간에 적용"으로 저장한다
- **THEN** `2026-10-10`은 야간(패턴 B)이고 패턴 이력은 비어 있다

#### Scenario: 기본 선택
- **WHEN** 저장된 패턴이 있는 상태에서 패턴을 고친 뒤 적용 범위 선택을 본다
- **THEN** "오늘부터 적용"이 선택되어 있다

#### Scenario: 첫 등록
- **WHEN** 저장된 패턴 없이 근무 패턴을 처음 등록한다
- **THEN** 적용 범위 선택은 표시되지 않고 새 패턴이 모든 날짜에 적용되며 이력은 비어 있다

#### Scenario: 초기화 후 다시 등록
- **WHEN** 이력이 있는 상태에서 근무 패턴 초기화 후 새 패턴을 등록한다
- **THEN** 적용 범위를 묻지 않고 저장되며, 기존 이력은 그대로 남고 새 패턴은 마지막 이력 이후의 날짜에 적용된다

#### Scenario: 변경 없이 저장
- **WHEN** 패턴을 바꾸지 않고(같은 근무 순서, 같은 오늘 위치) [저장]한다
- **THEN** 이력이 늘어나지 않고 모든 날짜의 근무가 그대로이다

#### Scenario: 적용 범위 선택 표시 조건
- **WHEN** 저장된 패턴이 있고 편집 내용이 저장된 패턴과 같다
- **THEN** 적용 범위 선택은 표시되지 않는다

### Requirement: 이력 갱신 규칙
같은 날 "오늘부터 적용"을 다시 저장하면 그날 시작된 패턴을 SHALL 덮어쓰고 이력에 빈 기간을 만들지 않는다. 오늘이 이력의 마지막 적용 종료일보다 이전이 되는 경우(기기 날짜가 과거로 바뀜)에는 오늘 이후 기록을 MUST 정리해 이력이 날짜순을 유지한다. 이력은 최대 50개이며, 초과하면 가장 오래된 기록을 버리고 그 기간은 다음으로 오래된 패턴으로 계산한다.

#### Scenario: 같은 날 다시 저장
- **WHEN** 오늘 "오늘부터 적용"으로 패턴 B를 저장한 뒤 같은 날 패턴 C를 "오늘부터 적용"으로 저장한다
- **THEN** 오늘부터는 패턴 C, 오늘 이전은 패턴 A이고 이력에는 패턴 A 하나만 남는다

#### Scenario: 이력 상한
- **WHEN** 이력이 50개인 상태에서 "오늘부터 적용"으로 한 번 더 저장한다
- **THEN** 이력은 50개를 넘지 않고 가장 오래된 기록이 사라지며 그 기간은 다음으로 오래된 패턴으로 계산된다

#### Scenario: 기기 날짜가 과거로 바뀜
- **WHEN** 이력의 마지막 종료일이 `2026-10-13`인데 기기 날짜가 `2026-10-05`로 바뀐 상태에서 "오늘부터 적용"으로 저장한다
- **THEN** 이력은 날짜순을 유지하고 `2026-10-05` 이전 날짜는 그날 적용되던 패턴으로, 이후는 새 패턴으로 계산된다

### Requirement: 패턴 이력 목록
근무 패턴 설정 화면은 저장된 패턴이 있거나 패턴 이력이 있을 때 **패턴 이력** 목록을 SHALL 표시한다. 목록은 현재 패턴(있으면)을 맨 위에 두고 이전 패턴을 최신순으로 이어서 보여 주며, 각 항목은 적용 기간과 근무 순서(근무 색과 한 글자 약어)를 보여 준다. 근무 유형은 색상만으로 구별해서는 MUST NOT 된다. 이력 항목을 수정·삭제하는 UI를 제공해서는 MUST NOT 된다. 이력이 없으면 아직 바꾼 기록이 없다는 문구를 보여 준다. 이전 패턴 항목은 누르면 편집기에 불러오며, 현재 패턴 항목은 누를 수 없다.

#### Scenario: 이력이 있는 목록
- **WHEN** 패턴 A가 `2026-10-12`까지 적용되었고 패턴 B가 `2026-10-13`부터 적용 중이다
- **THEN** 목록은 "2026년 10월 13일부터 (현재)" 패턴 B, "처음부터 2026년 10월 12일까지" 패턴 A 순서로 근무 순서와 함께 표시된다

#### Scenario: 이력 없음
- **WHEN** 한 번도 패턴을 "오늘부터 적용"으로 바꾸지 않았다
- **THEN** 현재 패턴과 함께 "바꾼 기록이 아직 없어요" 안내가 표시된다

#### Scenario: 읽기 전용
- **WHEN** 이력 목록의 어느 항목을 누른다
- **THEN** 이력을 수정·삭제하는 화면이나 선택 UI는 열리지 않고 저장된 이력은 그대로이다

#### Scenario: 현재 패턴 항목
- **WHEN** 이력 목록의 현재 패턴 항목을 누른다
- **THEN** 아무 일도 일어나지 않고 편집 내용은 그대로이다

#### Scenario: 첫 등록 화면
- **WHEN** 저장된 패턴도 패턴 이력도 없이 설정 화면을 연다
- **THEN** 패턴 이력 목록은 표시되지 않는다

#### Scenario: 패턴 초기화 뒤 목록
- **WHEN** 이력이 있는 상태에서 근무 패턴을 초기화한 뒤 근무 패턴 설정 화면을 연다
- **THEN** 현재 패턴 행 없이 이전 패턴이 최신순으로 표시된다

### Requirement: 이력 패턴 불러오기
이력 목록에서 이전 패턴 항목을 누르면 시스템은 그 패턴의 근무 순서를 편집 중인 근무 순서로 SHALL 바꾸고 오늘 위치 선택은 비운다. 불러오기만으로는 아무것도 저장해서는 MUST NOT 되며, 사용자가 오늘 위치를 고르고 [저장]해야 기존 저장 규칙(적용 범위 포함)대로 확정된다. 저장하지 않은 편집 내용이 있으면 덮어쓰기 전에 확인을 SHALL 받는다.

#### Scenario: 편집 내용이 없을 때 불러오기
- **WHEN** 패턴 B가 저장돼 있고 편집하지 않은 상태에서 이전 패턴 A(`[주간, 야간, 휴무]`) 항목을 누른다
- **THEN** 편집기의 근무 순서가 `[주간, 야간, 휴무]`가 되고 오늘 위치는 선택되지 않은 상태이며, 달력과 저장된 설정은 그대로이다

#### Scenario: 오늘 위치를 고르기 전
- **WHEN** 이전 패턴을 불러온 직후 [저장]을 본다
- **THEN** [저장]은 눌리지 않고 오늘에 해당하는 칸을 고르라는 안내가 보인다

#### Scenario: 불러온 뒤 저장
- **WHEN** 오늘이 `2026-10-19`이고 패턴 A를 불러와 첫째 칸을 오늘 위치로 고른 뒤 "오늘부터 적용"으로 저장한다
- **THEN** `2026-10-19`부터 패턴 A(기준일 `2026-10-19`)로 계산되고, 그 전날까지는 저장 전에 적용되던 패턴대로 유지되며 이력은 기존 "오늘부터 적용" 규칙대로 갱신된다

#### Scenario: 편집 중일 때 확인
- **WHEN** 근무 순서를 고친 뒤 저장하지 않고 이전 패턴 항목을 누른다
- **THEN** 편집 중인 내용을 바꿀지 묻는 확인 창이 열리고, 확인하면 불러오며 취소하거나 뒤로가기를 누르면 편집 내용이 그대로 남는다

#### Scenario: 패턴 초기화 뒤 다시 등록
- **WHEN** 근무 패턴을 초기화한 뒤 설정 화면에서 이전 패턴 A를 불러와 오늘 위치를 고르고 저장한다
- **THEN** 적용 범위를 묻지 않고 저장되며, 기존 이력은 그대로 남고 패턴 A는 마지막 이력 이후의 날짜에 적용된다

#### Scenario: 불러온 뒤 화면 나가기
- **WHEN** 이전 패턴을 불러온 뒤 저장하지 않고 뒤로가기를 누른다
- **THEN** 편집 내용이 있을 때와 같은 변경 폐기 확인 창이 열린다

### Requirement: 패턴이 없는 날짜
현재 근무 패턴이 없으면(근무 패턴 초기화 뒤) 이력의 마지막 종료일(`until`) 전날까지의 날짜는 그날 적용되던 이력의 패턴으로 SHALL 계산하고, 그 이후의 모든 날짜는 근무가 없는(패턴 없음) 날짜로 처리한다. 이력도 없으면 모든 날짜가 패턴 없음이다. 패턴 없음은 오류가 아니며 날짜 세부 내용으로 근무를 바꾸는 규칙에는 영향을 주지 않는다(MUST). 새 패턴을 등록하면 마지막 이력 이후의 날짜가 새 패턴으로 계산된다.

#### Scenario: 이력 없음·패턴 없음
- **WHEN** 이력도 현재 패턴도 없는 상태에서 임의 날짜를 계산한다
- **THEN** 모든 날짜가 패턴 없음이다

#### Scenario: 이력 종료일 경계
- **WHEN** 이력의 마지막 항목이 패턴 A를 `2026-10-13` 전날까지로 기록하고 현재 패턴이 없다
- **THEN** `2026-10-12`는 패턴 A로 계산되고 `2026-10-13`부터는 패턴 없음이다

#### Scenario: 다시 등록
- **WHEN** 위 상태에서 새 패턴 B를 등록한다
- **THEN** `2026-10-12` 이전은 패턴 A, `2026-10-13` 이후는 패턴 B로 계산된다
