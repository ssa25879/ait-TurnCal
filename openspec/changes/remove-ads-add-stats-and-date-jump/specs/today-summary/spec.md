## ADDED Requirements

### Requirement: 요약 추가 뒤 달력 화면 요소 유지
요약을 추가한 뒤에도 달력 격자, 월 이동, 하단 조작 요소(바로가기 줄과 대체 [설정] 버튼)는 기존과 같은 순서와 동작으로 SHALL 표시되며, 360px 폭에서 가로 스크롤이 생기거나 요소가 겹쳐서는 MUST NOT 된다. 요약 카드는 자체 광고 요소나 자사 유도 요소를 포함해서는 MUST NOT 된다.

#### Scenario: 좁은 화면
- **WHEN** 360px 폭에서 달력 화면을 연다
- **THEN** 요약 카드 두 개가 한 줄 또는 두 줄 안에서 잘림·겹침 없이 표시되고 달력 격자 7열이 모두 보인다

## REMOVED Requirements

### Requirement: 기존 달력 화면 요소 유지
**Reason**: 배너 광고 영역과 광고 간격 규칙이 사라져 요구사항 내용이 달라졌다. 광고를 뺀 같은 취지의 요구사항 "요약 추가 뒤 달력 화면 요소 유지"로 대체한다.
**Migration**: 격자·월 이동·하단 조작 요소 유지와 360px 규칙은 새 요구사항이 그대로 이어받는다. 광고 간격·광고 없음 시나리오는 광고 제거로 삭제한다.
