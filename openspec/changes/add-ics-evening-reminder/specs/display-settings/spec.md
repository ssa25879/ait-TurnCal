# Spec Delta

## MODIFIED Requirements

### Requirement: 설정 목록 화면
저장된 설정이 있으면 달력 화면은 설정 목록 화면으로 들어가는 진입점을 SHALL 제공한다. 설정 목록 화면은 "이름", "근무 패턴", "근무 유형", "화면 설정", "캘린더 알림", "초기화" 여섯 항목을 이 순서로 SHALL 표시하고, 각 항목을 누르면 해당 화면이 열린다. "근무 유형" 항목의 보조 문구는 바꾼 유형이 없으면 "기본값", 있으면 바꾼 유형 수를 보여 준다. "캘린더 알림" 항목의 보조 문구는 알림 시각("전날 21:00" 등) 또는 "알림 안 함"을 보여 준다.

#### Scenario: 설정 목록 진입
- **WHEN** 사용자가 달력 화면에서 설정 진입점을 누른다
- **THEN** "이름", "근무 패턴", "근무 유형", "화면 설정", "캘린더 알림", "초기화" 항목이 있는 설정 목록 화면이 열린다

#### Scenario: 근무 패턴 열기
- **WHEN** 설정 목록에서 "근무 패턴"을 누른다
- **THEN** 저장된 패턴과 오늘 위치가 채워진 근무 패턴 설정 화면이 열리고 화면 아래에 근무 패턴 초기화 버튼이 있다

#### Scenario: 근무 유형 열기
- **WHEN** 설정 목록에서 "근무 유형"을 누른다
- **THEN** 6종의 현재 이름·약어·색이 채워진 근무 유형 화면이 열리고 화면 끝에 [기본값으로 되돌리기]가 있다

#### Scenario: 근무 유형 보조 문구
- **WHEN** 오후와 야간 두 유형만 바꿔 저장한 뒤 설정 목록을 본다
- **THEN** "근무 유형" 항목 아래에 "2개 바꿈"이 표시되고, 기본값으로 되돌리면 "기본값"이 표시된다

#### Scenario: 화면 설정 열기
- **WHEN** 설정 목록에서 "화면 설정"을 누른다
- **THEN** 현재 테마 색과 주 시작 요일이 선택된 화면 설정 화면이 열리고 화면 아래에 화면 설정 초기화 버튼이 있다

#### Scenario: 캘린더 알림 열기
- **WHEN** 설정 목록에서 "캘린더 알림"을 누른다
- **THEN** 현재 알림 설정이 선택된 캘린더 알림 화면이 열린다

#### Scenario: 캘린더 알림 보조 문구
- **WHEN** 캘린더 알림을 바꾼 적 없이 설정 목록을 본다
- **THEN** "캘린더 알림" 항목 아래에 "전날 21:00"이 표시된다

#### Scenario: 이름 열기
- **WHEN** 설정 목록에서 "이름"을 누른다
- **THEN** 저장된 호칭과 근무표 이름이 채워진 이름 화면이 열린다

#### Scenario: 초기화 열기
- **WHEN** 설정 목록에서 "초기화"를 누른다
- **THEN** 전체 초기화 선택지만 있는 초기화 화면이 열린다
