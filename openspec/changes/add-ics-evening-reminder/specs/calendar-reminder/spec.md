# Spec Delta

## Purpose

캘린더 파일로 내보낸 근무 일정에 캘린더 앱이 울릴 전날 저녁 알림의 시각을 사용자가 정하고, 어떤 근무에 알림을 넣을지 규칙을 둔다. 알림은 턴캘이 보내지 않고 사용자가 가져온 캘린더 앱이 울린다.

## ADDED Requirements

### Requirement: 캘린더 알림 설정 화면
설정 목록의 "캘린더 알림"을 누르면 캘린더 알림 화면이 SHALL 열린다. 화면은 "알림 안 함", "전날 18:00", "전날 19:00", "전날 20:00", "전날 21:00", "전날 22:00", "전날 23:00" 일곱 선택지를 이 순서로 하나만 고를 수 있게 보여 주고, 현재 설정을 선택된 상태로 표시하며, "전날 21:00"에는 기본값임을 함께 표시한다. 화면은 알림이 캘린더 파일을 받아 캘린더 앱에 추가한 일정에서 울리고, 주간·오후·야간·당직 일정에만 들어가며(비번·휴무 제외), 이미 가져온 일정에는 반영되지 않아 다시 보내야 한다는 점을 SHALL 안내한다. 선택은 [저장] 없이 바로 저장된다.

#### Scenario: 기본 선택
- **WHEN** 캘린더 알림을 바꾼 적 없이 캘린더 알림 화면을 연다
- **THEN** 일곱 선택지 중 "전날 21:00"이 선택되어 있고 기본값 표시가 있다

#### Scenario: 시각 바꾸기
- **WHEN** "전날 20:00"을 고른 뒤 뒤로가기로 설정 목록에 돌아간다
- **THEN** "캘린더 알림" 항목 아래에 "전날 20:00"이 보이고, 앱을 다시 열어도 "전날 20:00"이 선택되어 있다

#### Scenario: 알림 끄기
- **WHEN** "알림 안 함"을 고른다
- **THEN** 설정 목록의 "캘린더 알림" 보조 문구가 "알림 안 함"이 된다

#### Scenario: 안내
- **WHEN** 캘린더 알림 화면을 연다
- **THEN** 알림은 캘린더 앱에 추가한 일정에서 울리고, 비번·휴무에는 들어가지 않으며, 바꾼 시각은 파일을 다시 보내야 반영된다는 안내가 보인다

### Requirement: 캘린더 알림 저장 실패
캘린더 알림 선택을 저장하지 못하면 선택을 이전 값으로 되돌리고 화면에 다시 시도하라는 오류 안내를 SHALL 표시한다.

#### Scenario: 저장 실패
- **WHEN** 저장소 쓰기가 실패하는 상태에서 "전날 22:00"을 고른다
- **THEN** 이전 선택이 다시 선택된 상태로 돌아가고 저장하지 못했다는 안내가 보인다

### Requirement: 알림 대상 근무
캘린더 파일 알림은 근무 유형의 내부 구분이 주간·오후·야간·당직인 일정에만 SHALL 들어가며, 비번·휴무 일정에는 넣어서는 MUST NOT 된다. 근무 유형 이름을 바꿔도 이 구분은 내부 유형을 따른다.

#### Scenario: 이름을 바꾼 휴무
- **WHEN** 휴무 이름을 "쉼"으로 바꾼 상태에서 캘린더 파일을 만든다
- **THEN** "쉼" 일정에는 알림이 없고 주간·야간 일정에는 알림이 있다
