# Spec Delta

## MODIFIED Requirements

### Requirement: 설정 화면 뒤로가기
저장된 설정이 있는 상태에서 뒤로가기를 누르면 설정 계층을 한 단계씩 SHALL 올라간다: 이름·근무 패턴 설정·화면 설정·초기화 화면은 설정 목록으로, 설정 목록은 달력으로 돌아간다. 근무 패턴 설정이나 이름 화면에 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인한다.

#### Scenario: 변경 없음
- **WHEN** 변경 없이 근무 패턴 설정 화면에서 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아간다

#### Scenario: 화면 설정에서 뒤로가기
- **WHEN** 화면 설정에서 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아가며 이미 바꾼 테마·주 시작 요일은 저장된 상태로 유지된다

#### Scenario: 초기화 화면에서 뒤로가기
- **WHEN** 초기화 화면에서 아무것도 실행하지 않고 뒤로가기를 누른다
- **THEN** 설정 목록 화면으로 돌아가고 데이터는 그대로이다

#### Scenario: 설정 목록에서 뒤로가기
- **WHEN** 설정 목록 화면에서 뒤로가기를 누른다
- **THEN** 달력 화면으로 돌아간다

#### Scenario: 변경 폐기 확인
- **WHEN** 근무 패턴 설정이나 이름 화면에 저장하지 않은 변경이 있는 상태로 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 설정 목록 화면으로 돌아가며 저장된 설정은 그대로이다

#### Scenario: 폐기 취소
- **WHEN** 폐기 확인에서 취소를 누른다
- **THEN** 편집 중이던 화면에 머무르고 편집 내용이 유지된다

#### Scenario: Android 시스템 백버튼
- **WHEN** Android 시스템 백버튼을 누른다
- **THEN** 토스 내비게이션 바 뒤로가기와 같은 규칙으로 동작한다

## ADDED Requirements

### Requirement: 날짜 화면 뒤로가기
날짜 화면에서 뒤로가기를 누르면 달력으로, 세부 내용 편집 화면에서 뒤로가기를 누르면 날짜 화면으로 SHALL 돌아간다. 편집 화면에 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인한다.

#### Scenario: 날짜 화면
- **WHEN** 날짜 화면에서 뒤로가기를 누른다
- **THEN** 달력 화면으로 돌아가고 보던 달이 유지된다

#### Scenario: 편집 중 뒤로가기
- **WHEN** 세부 내용 편집 화면에서 이름을 바꾼 뒤 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 날짜 화면으로 돌아간다
