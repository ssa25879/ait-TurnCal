# Proposal

## Why

교대근무자는 근무표를 가족·동료에게 보여 주거나 자주 쓰는 캘린더 앱에 옮겨 두고 싶어 하지만, 지금은 턴캘 화면 안에서만 볼 수 있다. 기획서 기능 후보 "일정 공유·내보내기(P2)"이며, 2026-10-19 사용자 결정으로 v1.2 세 번째 작업으로 진행한다.

## What Changes

- 달력 화면 하단(바로가기 줄 아래)에 **[이번 달 내보내기]**를 둔다. 현재 근무 패턴이 있을 때만 보인다. 누르면 바텀시트에서 두 가지 중 하나를 고른다:
  - **달력 이미지로 저장**: 보고 있는 달의 달력(근무표 이름, 요일, 날짜별 근무 약어·색, 쓰인 근무 유형 범례, 앱 이름)을 PNG 한 장으로 그려 기기에 저장한다.
  - **캘린더 파일로 저장**: 보고 있는 달의 날짜별 근무를 하루 종일 일정으로 담은 `.ics` 파일을 저장한다. 구글·삼성 등 캘린더 앱에서 가져올 수 있다. 각 일정 설명에 턴캘을 여는 토스 공유 링크(`intoss://ait-turncal`로 만든 링크)를 넣는다.
- 내용은 **근무만** 담는다. 날짜 세부 내용(이름·시간·메모)은 넣지 않는다. 바뀐 근무(세부 내용 분류)는 바뀐 근무 그대로 반영하고, 근무 유형 이름·약어·색 사용자 정의도 반영한다. 패턴이 없는 날은 비운다(이미지) / 넣지 않는다(.ics).
- 저장은 SDK `saveBase64Data`를 쓴다(권한 불필요). 지원하지 않는 토스 앱 버전이면 업데이트 안내를, 저장에 실패하면 실패 안내를 보여 주고, 성공하면 저장했다는 안내를 보여 준다.
- 공유 링크를 만들지 못하면 링크 없이 파일을 저장한다(저장 자체는 막지 않는다).
- 저장 형식(`turncal.settings`·`turncal.entries`)은 바뀌지 않는다.

## Capabilities

### New Capabilities

- `schedule-export`: 보고 있는 달의 근무를 달력 이미지(PNG)와 캘린더 파일(.ics)로 기기에 저장하는 진입점·내용 규칙·저장 결과 안내.

### Modified Capabilities

(없음 — 달력 하단 배치·배너 간격은 기존 `in-app-ads`의 "배너 위 마지막 요소와 32px" 규칙을 그대로 따르고, 바텀시트 뒤로가기는 `miniapp-shell`의 오버레이 우선 닫기 규칙을 그대로 따른다.)

## Impact

- 코드: 새 `src/domain/monthExport.ts`(달의 날짜별 근무 목록, .ics 문자열, base64 인코딩), 새 `src/export/renderMonthImage.ts`(Canvas 2D로 PNG 그리기), 새 `src/components/ExportSheet.tsx`, `CalendarScreen`(버튼), `App.tsx`(근무표 이름·근무 유형 전달), `src/style.css`.
- SDK: `saveBase64Data`(Android 5.218.0·iOS 5.216.0 이상), `Share.createLink`. 새 npm 의존성 없음.
- 테스트: 단위(날짜 목록·.ics 형식·인코딩), E2E 새 스크립트(다운로드 내용 검사), 달력 하단 요소가 바뀌므로 `banner`·`visual-audit`·`calendar-shortcuts`의 배치 검사 확인.
- 출시 가이드: 공유 링크는 `intoss://` 스킴만 쓴다(`intoss-private://` 금지 항목).
