# Spec Delta

## MODIFIED Requirements

### Requirement: 근무 유형
시스템은 정확히 6개의 근무 유형을 SHALL 제공한다. 기본 표시명과 약어는 주간("주"), 오후("오"), 야간("야"), 당직("당"), 비번("비"), 휴무("휴")이며, 사용자가 근무 유형 화면에서 이름·약어·색을 바꿨으면 그 값을 표시한다. 유형의 개수와 근무 계산 규칙은 표시 이름과 무관하다. 근무 유형 이름은 계산 규칙에 하드코딩된 교대제 명칭(예: 3교대)에 의존하지 않아야 한다(MUST NOT).

#### Scenario: 유형 목록
- **WHEN** 사용자가 패턴에 추가할 근무 유형을 고른다
- **THEN** 주간·오후·야간·당직·비번·휴무 6개 유형이 표시명과 한 글자 약어로 제공된다(바꾼 유형은 바꾼 이름·약어로)

#### Scenario: 자정을 넘는 근무의 표시 날짜
- **WHEN** 야간 또는 당직 근무가 자정을 넘어 끝난다
- **THEN** 해당 근무는 근무 시작일에만 표시된다

#### Scenario: 이름을 바꿔도 계산 동일
- **WHEN** 야간의 이름을 "밤"으로 바꾼다
- **THEN** 모든 날짜의 근무 계산 결과는 바꾸기 전과 같고 야간이던 날이 "밤"으로 표시된다
