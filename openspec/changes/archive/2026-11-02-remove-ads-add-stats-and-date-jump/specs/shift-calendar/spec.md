## ADDED Requirements

### Requirement: 연·월 직접 이동
사용자는 월 제목(예: "2026년 10월")을 눌러 연·월을 골라 그 달로 바로 이동할 수 SHALL 있다. 월 제목을 누르면 바텀시트가 열리고, 시트는 연도를 한 해씩 바꾸는 조작과 1월~12월 선택지를 보여 주며, 지금 보고 있는 연·월이 선택된 상태로 열린다. 선택 가능한 범위는 1970년 1월부터 2100년 12월까지이며 범위를 벗어나는 연도로는 이동할 수 없어야 한다(MUST). 월을 고르면 시트가 닫히고 그 달이 표시된다. 뒤로가기나 닫기로 시트를 닫으면 보던 달이 그대로 유지된다. 월 제목은 누를 수 있다는 것을 알 수 있게 표시하고(예: 제목 옆 화살표) 터치 영역은 44px 이상이어야 하며(MUST), 이전·다음 달 화살표와 [오늘] 버튼의 동작은 바뀌지 않는다. 연·월 이동은 저장된 데이터를 바꾸지 않는다.

#### Scenario: 연·월 선택으로 이동
- **WHEN** 2026년 10월을 보다가 월 제목을 눌러 연도를 2028년으로 바꾸고 3월을 고른다
- **THEN** 시트가 닫히고 2028년 3월 달력이 근무가 계산된 채 표시된다

#### Scenario: 현재 달 선택 상태
- **WHEN** 2026년 10월을 보다가 월 제목을 누른다
- **THEN** 시트에 2026년이 표시되고 10월이 선택된 상태로 보인다

#### Scenario: 범위 끝
- **WHEN** 시트에서 연도를 1970년까지 낮추거나 2100년까지 올린다
- **THEN** 1970년보다 이전, 2100년보다 이후로는 더 바꿀 수 없다

#### Scenario: 뒤로가기
- **WHEN** 시트가 열린 상태에서 뒤로가기를 누른다
- **THEN** 시트만 닫히고 보던 달이 그대로 유지되며 앱은 종료되거나 이전 화면으로 돌아가지 않는다

#### Scenario: 기존 이동 유지
- **WHEN** 연·월 직접 이동을 쓴 뒤 이전 달, 다음 달, [오늘]을 차례로 누른다
- **THEN** 각각 한 달 전, 한 달 뒤, 오늘이 속한 달이 표시된다

## MODIFIED Requirements

### Requirement: 근무 패턴·이름 수정 바로가기
달력 화면은 달력 격자 아래에 [근무 패턴 수정]과 [이름 수정] 바로가기 버튼을 SHALL 표시하고, 누르면 설정 목록을 거치지 않고 각각 근무 패턴 설정 화면과 이름 화면을 연다. 근무 패턴이 없는 달력에서는 [근무 패턴 등록하기] 안내 카드가 그 역할을 하므로 [근무 패턴 수정]을 표시해서는 MUST NOT 되고 [이름 수정]만 표시한다. 버튼은 날짜 칸·오늘·내일 카드·월 이동·[설정] 버튼의 동작과 배치를 가리거나 바꾸지 않아야 하며 360px 폭에서도 겹치거나 가로 스크롤을 만들지 않아야 한다. 설정 목록은 내비게이션 바의 "설정" 기능 버튼으로 열며, 기능 버튼을 쓸 수 없는 환경에서만 바로가기 줄 아래에 대체 [설정] 버튼을 표시한다.

#### Scenario: 근무 패턴 수정 바로가기
- **WHEN** 근무 패턴이 있는 달력에서 [근무 패턴 수정]을 누른다
- **THEN** 설정 목록이 아니라 근무 패턴 설정 화면이 바로 열리고 저장된 패턴이 불러와져 있다

#### Scenario: 이름 수정 바로가기
- **WHEN** 달력에서 [이름 수정]을 누른다
- **THEN** 설정 목록이 아니라 이름 화면이 바로 열리고 저장된 호칭·근무표 이름이 채워져 있다

#### Scenario: 패턴이 없는 달력
- **WHEN** 근무 패턴을 초기화한 뒤 달력을 연다
- **THEN** [근무 패턴 등록하기] 카드와 [이름 수정]은 보이고 [근무 패턴 수정]은 보이지 않는다

#### Scenario: 설정 버튼은 그대로
- **WHEN** 달력의 [설정](내비게이션 바 기능 버튼, 또는 기능 버튼을 쓸 수 없는 환경의 대체 하단 버튼)을 누른다
- **THEN** 설정 목록이 열리고 항목 4개가 그대로 표시된다

#### Scenario: 좁은 화면
- **WHEN** 360px 폭에서 근무표 이름이 최대 길이(20자)이고 호칭이 있는 달력을 본다
- **THEN** 바로가기 버튼이 다른 요소와 겹치지 않고 화면 안에 들어오며 가로 스크롤이 생기지 않는다
