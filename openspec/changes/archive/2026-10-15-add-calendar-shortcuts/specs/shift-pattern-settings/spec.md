# Spec Delta

## MODIFIED Requirements

### Requirement: 초기 설정 안내
저장된 설정이 없으면(첫 실행, 전체 초기화 뒤 재실행) 시스템은 별도의 안내 화면 없이 근무가 비어 있는 달력을 첫 화면으로 SHALL 표시하고, 달력의 "근무 패턴이 없어요" 카드의 패턴 등록 CTA로 근무 패턴 설정 화면에 진입시킨다. 안내를 바텀시트로 자동 표시해서는 MUST NOT 된다. 빈 달력을 표시하는 것만으로는 저장소에 아무것도 저장해서는 MUST NOT 된다.

#### Scenario: 최초 실행
- **WHEN** 저장된 설정 없이 앱을 처음 연다
- **THEN** 빈 달력과 [근무 패턴 등록하기] 카드가 표시되고 바텀시트는 뜨지 않으며 저장소는 비어 있다

#### Scenario: 설정 화면 진입
- **WHEN** 사용자가 [근무 패턴 등록하기]를 누른다
- **THEN** 패턴 설정(첫 등록) 화면이 열린다
