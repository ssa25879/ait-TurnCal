# Spec Delta

## MODIFIED Requirements

### Requirement: 광고를 넣지 않는 화면
달력 화면 외의 화면(근무 패턴 설정, 설정 목록, 화면 설정, 오류 안내)과 바텀시트·다이얼로그에는 광고를 표시해서는 MUST NOT 된다. 전면 광고와 리워드 광고는 표시하지 않는다. 저장된 설정이 없어 표시되는 빈 달력은 달력 화면이므로 배너가 표시될 수 있다.

#### Scenario: 설정 화면
- **WHEN** 설정 목록, 근무 패턴 설정, 화면 설정 중 어느 화면을 연다
- **THEN** 광고가 표시되지 않는다

#### Scenario: 진입 직후
- **WHEN** 미니앱을 처음 연다
- **THEN** 전면 광고나 광고 바텀시트가 나타나지 않는다
