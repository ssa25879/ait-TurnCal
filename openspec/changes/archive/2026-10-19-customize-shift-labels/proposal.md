# Proposal

## Why

근무 유형 6종(주간·오후·야간·당직·비번·휴무)의 이름·약어·색이 앱에 고정돼 있어, 직장마다 다른 호칭(예: "오후" 대신 "저녁", "당직" 대신 "대기")을 쓰는 사용자는 달력을 자기 근무표와 맞춰 읽기 어렵다. 기획서 기능 후보의 "근무 유형 사용자 정의(P2)"이며, 2026-10-19 사용자 결정으로 v1.2 두 번째 작업으로 진행한다.

## What Changes

- 설정 목록에 **"근무 유형"** 항목을 "근무 패턴"과 "화면 설정" 사이에 추가한다. 목록은 다섯 항목이 된다.
- 근무 유형 화면에서 6종 각각의 **이름(1~4자)·약어(1자)·색**을 바꿀 수 있다. 색은 글자 대비를 검증한 **고정 팔레트 10색**에서만 고르며, 토스 브랜드 색 계열은 넣지 않는다. 유형 개수와 내부 ID는 바꾸지 않는다(추가·삭제 없음).
- 6종끼리 이름이 겹치거나 약어가 겹치면 저장할 수 없다. 색만으로 근무를 구별하게 되는 상황을 막기 위해서다. 색은 겹쳐도 된다.
- 편집은 [저장]을 눌러야 반영되고, 저장 안 한 변경이 있으면 뒤로가기 때 기존 변경 폐기 확인을 쓴다(이름·근무 패턴 화면과 같다).
- 화면 끝에 **[기본값으로 되돌리기]**를 둔다. 확인 창을 거쳐 즉시 저장되고 화면에 머무른다.
- 바꾼 이름·약어·색은 달력 칸, 오늘·내일 요약, 날짜 화면, 세부 내용 분류, 패턴 편집기·오늘 위치·패턴 이력, 접근성 이름까지 앱 전체에 똑같이 쓰인다.
- 저장은 `turncal.settings`에 선택 필드 `shiftLabels`를 더하는 방식이라 `version: 3`을 유지한다. 기본값과 다른 유형만 저장한다. 이 필드를 모르는 이전 번들은 필드를 무시하고 기본 이름으로 보여 준다(롤백 안전).
- 전체 초기화는 이 설정도 지운다. 근무 패턴 초기화와 화면 설정 초기화는 이 설정을 건드리지 않는다.

## Capabilities

### New Capabilities

- `shift-labels`: 근무 유형 6종의 표시 이름·약어·색을 사용자가 정하는 화면, 입력 규칙(길이·중복), 색 팔레트, 저장·기본값 되돌리기, 앱 전체 반영.

### Modified Capabilities

- `shift-schedule`: "근무 유형" — 6종의 이름·약어를 고정값이 아니라 **기본값**으로 바꾸고, 사용자 정의가 있으면 그 값을 쓴다.
- `display-settings`: "설정 목록 화면" — 항목을 다섯 개("이름", "근무 패턴", "근무 유형", "화면 설정", "초기화")로 바꾼다.
- `settings-persistence`: 선택 필드 `shiftLabels`의 형식·검증·이전 번들 호환 요구사항을 추가한다.
- `settings-reset`: "전체 초기화"(지우는 목록과 경고문에 근무 유형 포함), "근무 패턴 초기화"(근무 유형 설정 유지, 초기화 뒤 접근 가능한 항목에 근무 유형 포함).
- `miniapp-shell`: "설정 화면 뒤로가기" — 근무 유형 화면도 설정 목록으로 돌아가고, 저장 안 한 변경이 있으면 폐기를 확인한다.

## Impact

- 코드: `src/domain/types.ts`(기본값 유지), 새 `src/domain/shiftLabels.ts`(팔레트·검증·기본값 병합), 표시 이름을 읽는 컴포넌트 7곳(`Calendar`, `DayScreen`, `EntryEditor`, `PatternEditor`, `PatternHistoryList`, `TodayPositionPicker`, `TodaySummary`), 새 `ShiftLabelsScreen`, `SettingsMenu`, `App.tsx`(뷰·뒤로가기·저장), `src/storage/scheduleStorage.ts`(필드 파싱·저장), `src/style.css`(근무 색을 변수로 덮어쓰기), 초기화 문구.
- 테스트: 단위(검증·병합·팔레트 대비·저장 파싱), E2E 새 스크립트와 설정 목록 항목 수·초기화 문구를 확인하는 기존 스크립트 수정.
- 의존성·광고·내비게이션 바·날짜 세부 내용 저장 형식(`turncal.entries`) 변경 없음.
