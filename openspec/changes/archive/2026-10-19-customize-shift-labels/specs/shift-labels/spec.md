# Spec Delta

## Purpose

근무 유형 6종의 표시 이름·한 글자 약어·색을 사용자가 자기 직장 호칭에 맞게 바꾸고, 바꾼 값이 앱의 모든 화면에 똑같이 쓰이도록 한다.

## ADDED Requirements

### Requirement: 근무 유형 화면
설정 목록의 "근무 유형"을 누르면 근무 유형 화면이 SHALL 열린다. 화면은 6종(주간·오후·야간·당직·비번·휴무 순서, 바꾼 경우 바꾼 이름)을 각각 현재 이름·약어·색 미리보기와 함께 보여 주고, 각 유형의 이름과 약어 입력, 색 선택을 제공한다. 유형을 추가하거나 삭제하는 UI는 제공해서는 MUST NOT 된다.

#### Scenario: 처음 열기
- **WHEN** 근무 유형을 바꾼 적 없는 사용자가 근무 유형 화면을 연다
- **THEN** 주간("주"), 오후("오"), 야간("야"), 당직("당"), 비번("비"), 휴무("휴")가 기본 색과 함께 이 순서로 표시된다

#### Scenario: 추가·삭제 없음
- **WHEN** 근무 유형 화면을 본다
- **THEN** 유형을 추가하거나 삭제하는 버튼은 없다

### Requirement: 이름·약어 입력 규칙
이름은 앞뒤 공백을 뺀 1~4자, 약어는 공백이 아닌 정확히 1자여야 SHALL 한다(글자 수는 사용자가 보는 글자 단위로 센다). 6종 사이에 같은 이름이나 같은 약어가 있으면 저장할 수 MUST 없으며, 화면은 어느 유형이 규칙을 어겼는지 그 입력 옆에 안내한다. 색은 여러 유형이 같은 색을 써도 된다.

#### Scenario: 이름 길이
- **WHEN** 오후의 이름을 비우거나 "저녁근무조"(5자)로 입력한다
- **THEN** [저장]이 막히고 오후 이름 입력 옆에 1~4자로 입력하라는 안내가 보인다

#### Scenario: 약어 길이
- **WHEN** 오후의 약어를 비우거나 "저녁"으로 입력한다
- **THEN** [저장]이 막히고 약어는 한 글자라는 안내가 보인다

#### Scenario: 약어 중복
- **WHEN** 당직의 약어를 "야"로 바꾼다(야간과 같음)
- **THEN** [저장]이 막히고 당직과 야간의 약어 입력 옆에 다른 유형과 겹친다는 안내가 보인다

#### Scenario: 이름 중복
- **WHEN** 비번의 이름을 "휴무"로 바꾼다
- **THEN** [저장]이 막히고 겹친다는 안내가 보인다

#### Scenario: 같은 색 허용
- **WHEN** 비번과 휴무에 같은 색을 고르고 이름·약어는 서로 다르다
- **THEN** 저장할 수 있다

### Requirement: 근무 유형 색 팔레트
색은 앱이 제공하는 고정 팔레트 10색에서만 SHALL 고른다. 팔레트의 각 색은 배경색과 글자색의 짝이며, 모든 짝은 글자 대비 4.5:1 이상이어야 하고(MUST) 토스 브랜드 색(`#3182F6`·`#0064FF` 계열)을 포함해서는 MUST NOT 된다. 기본 6색은 지금의 근무 색과 같다. 각 선택지는 색 이름을 접근성 이름으로 가진다.

#### Scenario: 선택지
- **WHEN** 한 유형의 색 선택을 본다
- **THEN** 10개 색 견본이 표시되고 현재 색이 선택되어 있으며, 각 견본에 그 유형의 약어가 그 색으로 표시된다

#### Scenario: 대비
- **WHEN** 팔레트의 모든 색 짝을 검사한다
- **THEN** 배경과 글자의 대비가 모두 4.5:1 이상이다

### Requirement: 근무 유형 저장
근무 유형 화면의 편집은 [저장]을 눌렀을 때만 SHALL 저장되고 반영된다. 저장에 성공하면 설정 목록으로 돌아가며, 실패하면 화면에 머물러 편집 내용을 유지한 채 오류를 MUST 안내한다. 기본값과 같은 유형은 사용자 정의가 없는 것으로 저장한다.

#### Scenario: 이름 바꾸기
- **WHEN** 오후의 이름을 "저녁", 약어를 "저"로 바꾸고 [저장]한다
- **THEN** 설정 목록으로 돌아가고 달력에서 오후였던 칸이 "저"로, 날짜 화면에서 "저녁"으로 표시된다

#### Scenario: 저장 전 반영 없음
- **WHEN** 이름을 고친 뒤 [저장]하지 않는다
- **THEN** 달력·요약·날짜 화면은 이전 이름 그대로이다

#### Scenario: 저장 실패
- **WHEN** 저장소 쓰기가 실패한다
- **THEN** 근무 유형 화면에 머무르고 편집 내용이 유지되며 저장하지 못했다는 안내가 보인다

### Requirement: 기본값으로 되돌리기
근무 유형 화면 끝에 [기본값으로 되돌리기]를 SHALL 둔다. 누르면 6종을 모두 기본 이름·약어·색으로 되돌린다는 확인 창이 열리고, 확인하면 즉시 저장되어 화면에 기본값이 표시된다. 확인 창에서 취소하거나 뒤로가기를 누르면 아무것도 바뀌어서는 MUST NOT 된다. 다른 설정과 데이터는 유지된다.

#### Scenario: 되돌리기
- **WHEN** 오후를 "저녁"으로 바꿔 저장한 뒤 [기본값으로 되돌리기]를 확인한다
- **THEN** 근무 유형 화면에 머무른 채 오후("오")가 기본 색으로 표시되고 달력도 "오"로 표시되며 패턴·이름·테마·세부 내용은 그대로이다

#### Scenario: 되돌리기 취소
- **WHEN** 확인 창에서 취소하거나 뒤로가기를 누른다
- **THEN** 확인 창만 닫히고 근무 유형 설정과 편집 내용이 그대로이다

### Requirement: 앱 전체 반영
저장된 근무 유형 이름·약어·색은 달력 칸, 오늘·내일 요약, 날짜 화면의 근무 줄, 세부 내용의 분류 선택지와 표시, 근무 패턴 편집기의 근무 버튼과 근무 순서, 오늘 위치 선택, 패턴 이력 목록, 각 요소의 접근성 이름에 SHALL 똑같이 쓰인다. 근무 계산·패턴·이력·세부 내용의 저장값은 바뀌어서는 MUST NOT 된다.

#### Scenario: 화면 간 일치
- **WHEN** 야간을 "밤"·"밤"·분홍으로 바꿔 저장한 뒤 야간 날짜를 달력 칸, 요약 카드, 날짜 화면, 패턴 편집기에서 본다
- **THEN** 모든 곳에 이름 "밤"·약어 "밤"·분홍 색으로 표시되고 접근성 이름에도 "밤"이 쓰인다

#### Scenario: 저장값 불변
- **WHEN** 근무 유형 이름을 바꿔 저장한다
- **THEN** 저장된 패턴의 근무 순서·패턴 이력·세부 내용의 분류 값은 바뀌지 않는다
