# Spec Delta

## MODIFIED Requirements

### Requirement: 설정 목록 화면
저장된 설정이 있으면 달력 화면은 설정 목록 화면으로 들어가는 진입점을 SHALL 제공한다. 설정 목록 화면은 "이름", "근무 패턴", "화면 설정", "초기화" 네 항목을 이 순서로 SHALL 표시하고, 각 항목을 누르면 해당 화면이 열린다.

#### Scenario: 설정 목록 진입
- **WHEN** 사용자가 달력 화면에서 설정 진입점을 누른다
- **THEN** "이름", "근무 패턴", "화면 설정", "초기화" 항목이 있는 설정 목록 화면이 열린다

#### Scenario: 근무 패턴 열기
- **WHEN** 설정 목록에서 "근무 패턴"을 누른다
- **THEN** 저장된 패턴과 오늘 위치가 채워진 근무 패턴 설정 화면이 열린다

#### Scenario: 화면 설정 열기
- **WHEN** 설정 목록에서 "화면 설정"을 누른다
- **THEN** 현재 테마 색과 주 시작 요일이 선택된 화면 설정 화면이 열린다

#### Scenario: 이름 열기
- **WHEN** 설정 목록에서 "이름"을 누른다
- **THEN** 저장된 호칭과 근무표 이름이 채워진 이름 화면이 열린다

#### Scenario: 초기화 열기
- **WHEN** 설정 목록에서 "초기화"를 누른다
- **THEN** 근무 패턴·화면 설정·전체 초기화 선택지가 있는 초기화 화면이 열린다
