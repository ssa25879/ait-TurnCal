# Spec Delta

## MODIFIED Requirements

### Requirement: 근무 패턴 초기화
근무 패턴 초기화는 저장된 패턴이 있을 때 근무 패턴 설정 화면 아래에 SHALL 제공된다. 실행하면 현재 반복 패턴과 기준일만 지우고 패턴 이력·화면 설정·이름·날짜 세부 내용은 유지하며, 근무 패턴 등록 안내 화면이 표시된다. 저장된 패턴이 없는 최초 등록 화면에는 이 버튼을 두어서는 MUST NOT 된다.

#### Scenario: 패턴 초기화
- **WHEN** 근무 패턴 설정 화면 아래의 근무 패턴 초기화를 누르고 확인한다
- **THEN** 근무 패턴 등록 안내 화면이 표시되고, 새 패턴을 저장하면 기존 테마·주 시작 요일·이름·세부 내용이 그대로 적용된다

#### Scenario: 이력은 유지
- **WHEN** 패턴 이력이 있는 상태에서 근무 패턴 초기화를 확인한 뒤 새 패턴을 등록한다
- **THEN** 이전 패턴 이력은 그대로 남아 있고, 새 패턴은 마지막 이력 이후의 날짜에 적용되며 패턴 이력 목록에 이전 기록과 새 패턴이 함께 표시된다

#### Scenario: 편집 중 초기화
- **WHEN** 근무 패턴 설정 화면에서 패턴을 고친 뒤 저장하지 않고 근무 패턴 초기화를 확인한다
- **THEN** 고치던 내용과 저장된 현재 패턴이 지워지고 근무 패턴 등록 안내 화면이 표시된다

#### Scenario: 최초 등록
- **WHEN** 저장된 패턴 없이 근무 패턴을 처음 등록한다
- **THEN** 등록 화면에 근무 패턴 초기화 버튼이 보이지 않는다

### Requirement: 전체 초기화
전체 초기화는 설정(근무 패턴, 패턴 이력, 화면 설정, 이름), 날짜 세부 내용, 사용자 식별키 저장값을 포함한 턴캘의 모든 로컬 저장 데이터를 SHALL 삭제하고 처음 실행한 상태로 돌아간다. 확인 창은 근무 패턴과 **패턴 이력**을 포함해 무엇이 지워지는지와 되돌릴 수 없음을 경고해야 한다(MUST). 사용자 식별키는 다음 실행 때 다시 받아 저장된다.

#### Scenario: 전체 초기화
- **WHEN** 전체 초기화를 확인한다
- **THEN** 초기 안내 화면이 인디고 테마로 표시되고, 앱을 다시 열어도 설정과 세부 내용이 없으며 저장된 값은 새로 받은 사용자 식별키뿐이다

#### Scenario: 이력까지 삭제
- **WHEN** 패턴 이력이 있는 상태에서 전체 초기화를 확인한 뒤 새 패턴을 등록한다
- **THEN** 이전 패턴 이력은 남아 있지 않고 새 패턴이 모든 날짜에 적용되며 패턴 이력 목록은 비어 있다

#### Scenario: 경고문
- **WHEN** 전체 초기화를 누른다
- **THEN** 확인 창에 근무 패턴·패턴 이력·화면 설정·이름·날짜 세부 내용이 모두 지워지고 되돌릴 수 없다는 경고가 표시된다
