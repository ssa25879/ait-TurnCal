# Spec Delta

## MODIFIED Requirements

### Requirement: 전체 초기화
전체 초기화는 설정, 날짜 세부 내용, 사용자 식별키 저장값을 포함한 턴캘의 모든 로컬 저장 데이터를 SHALL 삭제하고 처음 실행한 상태로 돌아간다. 사용자 식별키는 다음 실행 때 다시 받아 저장된다.

#### Scenario: 전체 초기화
- **WHEN** 전체 초기화를 확인한다
- **THEN** 초기 안내 화면이 인디고 테마로 표시되고, 앱을 다시 열어도 설정과 세부 내용이 없으며 저장된 값은 새로 받은 사용자 식별키뿐이다
