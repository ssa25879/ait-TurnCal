# Proposal

## Why

v1은 월간 달력만 보여 주기 때문에 "오늘·내일 근무가 뭐지?"를 확인하려면 달력에서 오늘·내일 칸을 찾아 작은 한 글자 약어를 읽어야 한다. 교대근무자가 앱을 여는 가장 흔한 이유가 바로 이 확인이다. 기획서 P1 "오늘/내일 근무 요약"(첫 화면에서 2일간 근무 표시)이 v1에서 구현되지 않았고, 도메인 계산(`getEffectiveShift`)·공휴일·날짜 이동·자정 갱신이 모두 이미 있어 변경 규모가 작다.

## What Changes

- 달력 화면 맨 위(근무표 이름 아래, 월 이동줄 위)에 **오늘·내일 요약 카드 2개**를 추가한다.
- 카드마다 날짜(`M월 D일 (요일)`), 근무 유형(색 + 약어 + 이름), 공휴일 이름(있을 때)을 보여 준다.
- 날짜 세부 내용으로 근무가 바뀐 날은 "바뀐 근무" 표시와 바뀐 근무 유형을 보여 주고, 시작 시간이 있는 세부 내용이 있으면 첫 항목의 시간(`HH:MM~HH:MM`)을 함께 보여 준다.
- 카드를 누르면 그 날짜의 날짜 화면이 열린다(달력 칸과 같은 동작).
- 요약은 항상 **오늘 기준**이며 보고 있는 달과 무관하다. 자정을 넘겨 앱이 다시 보이면 오늘·내일이 갱신된다.
- 저장 형식·설정 항목·광고·권한은 바뀌지 않는다. 기존 사용자 데이터는 그대로 호환된다.

## Capabilities

### New Capabilities
- `today-summary`: 달력 화면 상단의 오늘·내일 근무 요약(표시 내용, 바뀐 근무·공휴일·시간 반영, 누르면 날짜 화면 이동, 날짜 변경 시 갱신)

## Impact

- 코드: `src/components/CalendarScreen.tsx`(요약 영역 삽입), 새 컴포넌트 `src/components/TodaySummary.tsx`, 새 도메인 함수 `src/domain/summary.ts`(오늘·내일 요약 값 계산), `src/style.css`(카드 스타일).
- 테스트: 도메인 단위 테스트 추가, 브라우저 E2E(`scripts/e2e/`)에 요약 시나리오 추가, 기존 E2E 중 달력 위치·광고 간격을 가정한 검사 재확인.
- 레이아웃 위험: 요약 때문에 달력이 아래로 밀려 배너 광고·설정 버튼 간격(32px 이상) 규칙과 360px 폭 표시를 다시 확인해야 한다.
- 출시: 새 번들 업로드 → 실기기 확인 → 업데이트 검토. 출시 가이드 대조표를 다시 확인한다.
- 의존성·권한·네트워크·저장 스키마 변경 없음.
