# Spec Delta

## ADDED Requirements

### Requirement: 패턴이 없는 달력
저장된 설정이 있으나 현재 근무 패턴이 없는 경우(근무 패턴 초기화 뒤) 시스템은 등록 안내 대신 **달력**을 SHALL 표시한다. 패턴이 없는 날짜의 칸은 근무 배지 없이 날짜(와 공휴일 표시)만 보여 주며 눌러서 날짜 화면을 열 수 있다. 달력 위쪽에는 "근무 패턴이 없어요"라는 안내와 [근무 패턴 등록하기] 버튼을 표시하고, 버튼은 근무 패턴 설정 화면을 연다. 날짜 세부 내용으로 근무를 바꿔 둔 날은 그 근무를 평소처럼 표시해야 한다(MUST). 날짜 화면은 패턴이 없는 날의 근무 줄에 "근무 패턴이 없어요"를 보여 주고 세부 내용 추가·수정은 그대로 제공한다.

#### Scenario: 패턴 초기화 직후
- **WHEN** 패턴 이력이 없는 상태에서 근무 패턴을 초기화한다
- **THEN** 달력 화면이 표시되고 모든 칸에 근무 배지가 없으며 "근무 패턴이 없어요" 안내와 [근무 패턴 등록하기] 버튼이 보인다

#### Scenario: 이력이 남아 있는 달력
- **WHEN** 이력의 마지막 종료일이 `2026-10-13`이고 현재 패턴이 없는 상태로 2026년 10월 달력을 본다
- **THEN** `2026-10-12` 이전 칸은 이력의 패턴으로 근무가 표시되고 `2026-10-13` 이후 칸은 근무 배지가 없다

#### Scenario: 바뀐 근무는 유지
- **WHEN** 패턴이 없는 날짜에 분류 "휴무" 세부 내용이 있다
- **THEN** 그 칸에 "휴"가 휴무 색상으로 표시되고 "바뀐 근무" 표시가 보인다

#### Scenario: 등록하기 버튼
- **WHEN** [근무 패턴 등록하기]를 누른다
- **THEN** 근무 패턴 설정(첫 등록) 화면이 열리고, 저장하면 달력 화면에 새 패턴의 근무가 표시된다

#### Scenario: 날짜 화면
- **WHEN** 패턴이 없는 날짜의 칸을 누른다
- **THEN** 날짜 화면에 "근무 패턴이 없어요"가 표시되고 [세부 내용 추가]를 쓸 수 있다
