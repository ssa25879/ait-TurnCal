# Spec Delta

## MODIFIED Requirements

### Requirement: 최초 화면 뒤로가기 시 종료
최초 화면에서 뒤로가기(토스 내비게이션 바 또는 Android 시스템 백버튼)를 누르면 미니앱이 SHALL 종료된다. 최초 화면은 저장된 설정이 있으면(근무 패턴이 없어도) 달력, 저장된 설정이 없으면 초기 설정 화면이다.

#### Scenario: 달력에서 뒤로가기
- **WHEN** 저장된 설정이 있는 상태로 달력 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 패턴이 없는 달력에서 뒤로가기
- **WHEN** 근무 패턴을 초기화한 뒤 표시된 달력 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 초기 설정 흐름에서 뒤로가기
- **WHEN** 저장된 설정이 없는 상태로 초기 안내 또는 첫 설정 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 패턴이 없는 상태의 설정 계층
- **WHEN** 패턴이 없는 달력에서 [근무 패턴 등록하기]로 근무 패턴 설정 화면을 연 뒤 변경 없이 뒤로가기를 누른다
- **THEN** 설정 계층 규칙에 따라 설정 목록이 아니라 달력으로 돌아가며 미니앱은 종료되지 않는다
