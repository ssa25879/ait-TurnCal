# Proposal

## Why

실기기 확인에서 "바로가기 버튼이 너무 크다"는 피드백이 나왔고, 디자인 감사(2026-10-15)에서 출시 가이드에 걸리는 값(10px 글자, 44px 미만 터치 영역, 낮은 대비)과 화면 간 불일치(둥근 모서리·글자 크기 기준 없음, 선택 카드 스타일 제각각, 저장 버튼 아래의 초기화 영역)가 확인됐다. 사용자 결정(2026-10-15): 가장 불편한 화면은 **날짜 화면·세부 내용 편집·설정 계열**이고, **달력 첫 화면에 6주 격자가 모두 보이게** 하며, 오늘·내일 카드는 2장을 유지하고 토요일 색은 테마색을 그대로 따른다.

## What Changes

외형(스타일·마크업 구조) 전용이며 동작·저장 형식·OpenSpec 계약 문장은 바꾸지 않는다.

- **가이드 위반 수정(P0):** 10px 글자(`.cycle-item-order`, `.today-badge`)를 11px 이상으로, 월 이동 버튼과 시간 지우기 버튼의 누르는 영역을 44px 이상으로, 공휴일 글자색 대비와 이번 달 밖 날짜의 투명도를 올린다.
- **달력 첫 화면:** 칸 높이를 줄여 360×740(및 390×844)에서 6주 격자가 스크롤 없이 모두 보이게 한다. 근무 배지 크기를 칸·카드·날짜 화면에서 통일하고 오늘 표시(테두리 + 연한 배경)를 칸과 카드가 같게 한다. 이름 헤더의 위계(근무표 이름 강조, 호칭 보조)를 정리하고 하단 버튼 줄의 무게를 맞춘다.
- **날짜 화면·세부 내용 편집·설정 계열(우선 범위):** 주 동작 버튼([저장] 등)을 위험 동작(초기화)보다 위에 두고, 선택 카드(`.theme-option`·`.scope-option`·`.category-option`)를 공용 스타일로 통일하고, 날짜 화면의 "그날 근무로 적용" 선택지가 테마 전용 클래스를 빌려 쓰는 것을 공용 클래스로 바꾼다. 분류 선택지 줄바꿈(4+3)을 정리한다.
- **기준값 도입:** 둥근 모서리·간격·글자 크기를 CSS 변수(소수 단계)로 정리해 같은 값을 한 곳에서 쓴다. 결과 화면은 위 항목 외에는 거의 같게 유지한다.
- **하지 않는 것:** 오늘·내일 카드 형태 변경, 토요일 색 변경, 새 테마, 하단 고정 CTA, 동작·명세가 바뀌는 항목(별도 change `move-settings-to-navbar`).

## Impact

- 코드: `src/style.css`(대부분), `src/components/Calendar.tsx`·`CalendarScreen.tsx`·`DayScreen.tsx`·`EntryEditor.tsx`·`SettingsScreen.tsx`·`DisplaySettingsScreen.tsx`·`PatternEditor.tsx`·`TodayPositionPicker.tsx`·`ResetAction.tsx`(마크업·클래스).
- 테스트: 단위 테스트 영향 없음. E2E 9종(349개)이 클래스·문구·높이·간격에 의존하므로 선택자를 유지하거나 함께 고치고(공용 클래스 추가 시 기존 클래스는 남김), 11px 미만 글자·44px 터치 영역·가로 스크롤 검사를 새로 추가한다.
- 호환성: 저장 데이터·`version` 변경 없음. 롤백은 이전 번들로 되돌리면 된다.
- 출시 가이드: 위반을 줄이는 방향이다. 새 오버레이·외부 이동·권한 없음.
- 선행 조건: `add-calendar-shortcuts`(실기기 확인 → 아카이브 → `main` 병합)가 끝난 뒤 시작한다(하단 버튼 줄이 그 결과물).
