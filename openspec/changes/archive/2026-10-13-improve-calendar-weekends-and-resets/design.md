# Design

## Context

- 요구사항은 `specs/calendar-holidays`, `specs/settings-reset`, `specs/display-settings` 참고. 동기는 proposal.md - Why.
- 달력 칸(`Calendar.tsx`)은 날짜 숫자 · 근무 글자(30px) · 세부 내용 표시 줄(16px)로 이루어진 버튼이고, 칸 높이는 `min-height: 72px`로 고정돼 있다. 360px 기기에서 칸 너비는 약 43px이다.
- 요일 머리글은 이미 `is-sunday`(`--color-danger`)·`is-saturday`(`--color-primary`)를 쓴다.
- 초기화 로직(`storage/reset.ts`)과 `App.runReset`은 그대로 쓸 수 있다. 바뀌는 것은 버튼 위치와 실행 후 머무를 화면뿐이다.

## Goals / Non-Goals

**Goals:**
- 공휴일 판정은 오프라인·동기 함수 하나(`getHolidays(date)`)로 달력과 날짜 화면이 같이 쓴다.
- 공휴일 자료의 근거(법령·천문연 자료)를 코드 주석과 테스트로 남겨 다음 갱신 때 같은 방법으로 검증할 수 있게 한다.

**Non-Goals:**
- 임시공휴일 자동 반영, 서버·API 조회.
- 공휴일에 따른 근무 자동 변경.
- 2036년 이후 자료(앱 업데이트로 추가).

## Decisions

### D1. 공휴일 = 음력 표 + 규칙 계산 + 선거일 표
- 자료가 연도별로 바뀌는 부분만 표로 둔다.
  - **음력 공휴일:** 연도별 설날(음력 1월 1일)·부처님 오신 날(음력 4월 8일)·추석(음력 8월 15일)의 양력 날짜. 한국천문연구원 음양력 변환(`astro.kasi.re.kr/life/lunc/between`, 2026-10-13 조회) 값을 그대로 옮긴다. 설날 전날·다음 날, 추석 전날·다음 날은 ±1일(음력 연속일)이다.
  - **선거일:** 「관공서의 공휴일에 관한 규정」 제2조제10호의2(임기만료에 의한 선거). 「공직선거법」 제34조(대통령 70일·국회 50일·지방 30일 전 이후 첫 수요일, 민속절·공휴일이거나 전날·다음 날이 공휴일이면 다음 주 수요일)로 계산한 날짜를 표로 둔다: 2026-06-03(지방, 확정), 2028-04-12(국회), 2030-03-27(대통령, 임기만료 2030-06-03 기준), 2030-06-12(지방, 6-05 다음 날 현충일 → 다음 주), 2032-04-14(국회), 2034-05-31(지방). 2028년 이후는 선관위 공고 전 계산값이라 주석에 표시한다.
- 고정 날짜 공휴일과 대체공휴일은 현행 규정(대통령령 제36290호, 2026-05-01 시행 — 노동절·제헌절 공휴일화)의 제2조·제3조를 코드로 옮겨 연도별로 계산한다. 범위가 2026-01-01부터라 노동절(2026-05-01)·제헌절(2026-07-17)도 시행일 이후다.
- 대안: 날짜를 모두 나열한 완성 표(약 190건). 계산 규칙이 없어 검토는 쉽지만, 대체공휴일 오류를 사람이 찾기 어렵다. 규칙 + 공식 발표와 대조하는 테스트가 더 안전하다.
- 용량: 음력 표 10행 + 선거일 6건 + 규칙 함수. 실측(2026-10-13 vite build) 배포 JS 1,184.52KB → 1,187.32KB(+2.8KB, gzip +1.1KB), CSS +0.4KB. 연도마다 음력 표 한 줄(약 40B)이 늘어 이후 연도 추가 부담은 무시할 수준이다. 연도별 결과는 처음 조회할 때 계산해 메모해 둔다.

### D2. 대체공휴일 계산
- 제3조를 다음처럼 구현한다.
  - 대상 A(제2호 국경일 5개, 부처님 오신 날, 노동절, 어린이날, 기독탄신일): 토·일과 겹치거나 평일에 다른 공휴일과 겹치면 대체.
  - 대상 B(설·추석 연휴 각 3일): 일요일과 겹치거나 평일에 다른 공휴일과 겹치면 대체(토요일은 대체 없음).
  - 대상 아님: 1월 1일, 현충일, 선거일(다른 공휴일과 겹침 판단에는 포함).
- 날짜별로 "잃은 날 수"를 센다: 주말이면 대체 대상 공휴일 수, 평일이면 `min(공휴일 수 - 1, 대체 대상 수)`. 날짜순으로 처리하며 잃은 날마다 그 날 다음의 첫 비공휴일(토·일·공휴일·이미 정한 대체공휴일이 아닌 날, 제3조 ②③)을 대체공휴일로 정한다.
- 검증: 우주항공청 「2027년 월력요항」(2026-06-29) 대체공휴일 7일과 공휴일 총 72일(일요일 포함 중복 제거), 2026년 대체공휴일 4일(03-02, 05-25, 08-17, 10-05)을 단위 테스트로 고정한다.

### D3. 이름과 칸 표시
- 각 공휴일은 `{ name, short }`를 가진다. 전체 이름은 날짜 화면·접근성 이름에, `short`(최대 3자)는 칸에 쓴다. 예: 부처님 오신 날/부처님, 어린이날/어린이, 기독탄신일/성탄절, 설날 전날/설날, 대체공휴일은 "광복절 대체공휴일"/"대체", 선거일은 "국회의원선거일"/"선거일".
- 칸 구조: 날짜 숫자 아래에 11px 공휴일 줄(높이 14px, 모든 칸에 확보)을 넣는다. 칸 `min-height`는 72px → 86px. 11px는 디자인 기준 최소 글자 크기다.
- 날짜 숫자 색 우선순위: 공휴일·일요일 → `--color-danger`, 토요일 → `--color-primary`, 그 외 기본. 요일은 칸 위치가 아니라 날짜에서 계산한다(`weekdayOf`를 `calendar.ts`에서 내보낸다).

### D4. 초기화 버튼 배치
- `ResetScreen`은 전체 초기화만 남기고, 확인 다이얼로그·실패 안내 패턴은 공통 컴포넌트 `ResetAction`(제목·설명·확인 문구·실행 함수)으로 뽑아 세 화면이 같이 쓴다. 확인 다이얼로그의 뒤로가기 닫기(`useCloseOnBack`)도 컴포넌트 안에 둔다.
- `SettingsScreen`은 `onResetPattern`이 주어질 때(저장된 패턴이 있는 편집 흐름)만 버튼을 그린다. 최초 등록·[다시 설정] 흐름은 넘기지 않는다.
- 근무 패턴 초기화 성공 시 기존처럼 등록 안내 화면으로 이동하므로 편집 중 내용(dirty)은 함께 버려진다. 폐기 확인은 초기화 확인 창이 대신한다.
- 화면 설정 초기화는 성공 후 화면 설정에 머문다(현재는 설정 목록으로 이동). 실패 시 저장 전 값으로 되돌리고 화면 설정에서 안내한다.

## Risks / Trade-offs

- [임시공휴일·법 개정을 앱이 모른다] → 표시 전용이라 근무 계산에는 영향이 없다. 공휴일 규정이 바뀌면 `holidays.ts`와 대조 테스트를 갱신해 앱을 업데이트한다. 갱신 방법을 파일 머리 주석에 적는다.
- [2028년 이후 선거일은 계산값] → 대선 조기 실시(궐위) 같은 변수는 반영할 수 없다. 선관위 공고 때 표를 고친다.
- [칸 높이 증가로 배너가 아래로 밀림] → 달력 화면은 이미 스크롤 화면이다. 390×844·360×640 스크린샷으로 격자·배너 위치를 확인한다.
- [공휴일과 세부 내용 표시가 한 칸에 몰림] → 공휴일 줄과 세부 내용 줄을 분리하고 둘 다 한 줄 말줄임 처리한다.

## Migration Plan

- 저장 형식 변화 없음. 배포 후 문제가 있으면 이전 번들로 롤백하면 된다.
