# Spec Delta

## MODIFIED Requirements

### Requirement: 전체 초기화
전체 초기화는 설정(근무 패턴, 패턴 이력, 화면 설정, 이름), 날짜 세부 내용, 사용자 식별키 저장값을 포함한 턴캘의 모든 로컬 저장 데이터를 SHALL 삭제하고 처음 실행한 상태로 돌아간다. 처음 실행한 상태는 별도 안내 화면 없이 근무가 비어 있는 달력이며, 이 빈 달력은 저장하지 않은 기본 설정으로만 표시되어 앱을 다시 열어도 같은 빈 달력이 열린다. 확인 창은 근무 패턴과 **패턴 이력**을 포함해 무엇이 지워지는지와 되돌릴 수 없음을 경고해야 한다(MUST). 사용자 식별키는 다음 실행 때 다시 받아 저장된다.

#### Scenario: 전체 초기화
- **WHEN** 전체 초기화를 확인한다
- **THEN** 빈 달력이 인디고 테마로 표시되고, 앱을 다시 열어도 설정과 세부 내용이 없으며 저장된 값은 새로 받은 사용자 식별키뿐이다

#### Scenario: 전체 초기화 뒤 뒤로가기
- **WHEN** 전체 초기화를 확인한 뒤(또는 앱을 다시 연 뒤) 표시된 빈 달력에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 이력까지 삭제
- **WHEN** 패턴 이력이 있는 상태에서 전체 초기화를 확인한 뒤 새 패턴을 등록한다
- **THEN** 이전 패턴 이력은 남아 있지 않고 새 패턴이 모든 날짜에 적용되며 패턴 이력 목록은 비어 있다

#### Scenario: 경고문
- **WHEN** 전체 초기화를 누른다
- **THEN** 확인 창에 근무 패턴·패턴 이력·화면 설정·이름·날짜 세부 내용이 모두 지워지고 되돌릴 수 없다는 경고가 표시된다
