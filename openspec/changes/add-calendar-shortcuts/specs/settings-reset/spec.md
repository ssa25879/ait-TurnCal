# Spec Delta

## ADDED Requirements

### Requirement: 전체 초기화 뒤 뒤로가기
전체 초기화를 마치면 지금처럼 초기 등록 안내 화면이 표시되고, 거기서(또는 안내에서 연 근무 패턴 첫 등록 화면에서) 뒤로가기를 누르면 미니앱이 종료되지 않고 **근무가 비어 있는 달력**이 SHALL 표시된다. 이 빈 달력은 화면에만 있는 기본 상태이며 저장소에는 아무것도 저장해서는 MUST NOT 된다(앱을 다시 열면 첫 실행처럼 초기 등록 안내가 나온다). 빈 달력에서 뒤로가기를 한 번 더 누르면 미니앱이 종료된다. 저장된 설정이 없는 진짜 첫 실행의 뒤로가기(종료)는 바뀌지 않는다.

#### Scenario: 전체 초기화 후 등록 안내에서 뒤로가기
- **WHEN** 전체 초기화를 마친 뒤 초기 등록 안내 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료되지 않고 근무 배지가 없는 달력과 [근무 패턴 등록하기] 안내가 표시되며 저장소는 비어 있는 그대로이다

#### Scenario: 등록 화면에서 뒤로가기
- **WHEN** 전체 초기화 뒤 [패턴 등록하기]로 연 근무 패턴 설정 화면에서 뒤로가기를 누른다
- **THEN** 빈 달력이 표시된다

#### Scenario: 빈 달력에서 등록
- **WHEN** 위 빈 달력에서 [근무 패턴 등록하기]로 패턴을 등록하고 저장한다
- **THEN** 달력에 새 패턴의 근무가 표시되고 그때부터 설정이 저장된다

#### Scenario: 빈 달력에서 뒤로가기
- **WHEN** 전체 초기화 뒤 표시된 빈 달력에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

#### Scenario: 첫 실행은 그대로
- **WHEN** 저장된 설정이 없는 첫 실행에서 초기 등록 안내 화면의 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다
