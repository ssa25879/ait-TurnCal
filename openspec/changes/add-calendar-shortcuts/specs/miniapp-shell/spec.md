# Spec Delta

## ADDED Requirements

### Requirement: 달력 바로가기로 연 화면의 뒤로가기
달력의 [근무 패턴 수정]·[이름 수정]·[근무 패턴 등록하기]로 연 화면에서 뒤로가기(토스 내비게이션 바 또는 Android 시스템 백버튼)를 누르면 설정 목록이 아니라 **달력**으로 SHALL 돌아가며 미니앱은 종료되지 않는다. 저장하지 않은 변경이 있으면 먼저 변경 폐기 여부를 MUST 확인하고, 폐기를 확인하면 달력으로 돌아가며 취소하면 편집 중인 화면에 그대로 머문다. 설정 목록을 거쳐 연 화면의 뒤로가기 계층(상세 → 설정 목록 → 달력)은 바뀌지 않는다.

#### Scenario: 변경 없이 뒤로가기
- **WHEN** 달력의 [이름 수정]으로 이름 화면을 연 뒤 변경 없이 뒤로가기를 누른다
- **THEN** 달력이 표시되고 미니앱은 종료되지 않는다

#### Scenario: 변경 폐기 확인 후 달력 복귀
- **WHEN** [근무 패턴 수정]으로 연 화면에서 패턴을 고친 뒤 뒤로가기를 누르고 폐기를 확인한다
- **THEN** 변경이 버려지고 달력이 표시되며 저장된 패턴은 그대로이다

#### Scenario: 폐기 취소
- **WHEN** 위 확인 창에서 계속 편집하기를 누른다
- **THEN** 편집 중이던 화면과 입력 내용이 그대로 남는다

#### Scenario: 설정 목록 경로는 그대로
- **WHEN** [설정] → 설정 목록 → 이름 화면을 연 뒤 뒤로가기를 누른다
- **THEN** 설정 목록으로 돌아가고 한 번 더 누르면 달력으로 돌아간다

#### Scenario: 바로가기 뒤 달력에서 종료
- **WHEN** 바로가기로 연 화면에서 뒤로가기로 달력에 돌아온 뒤 한 번 더 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다
