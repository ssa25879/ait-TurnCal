# Spec Delta

## MODIFIED Requirements

### Requirement: 주 시작 요일 설정
달력은 사용자가 화면 설정에서 고른 주 시작 요일(일요일 또는 월요일)을 SHALL 따르며 기본값은 일요일이다. 달력 화면에는 주 시작 요일 선택 UI를 두어서는 MUST NOT 되며, 변경은 화면 설정에서 즉시 저장되어 달력에 반영된다.

#### Scenario: 월요일로 변경
- **WHEN** 사용자가 화면 설정에서 주 시작 요일을 월요일로 바꾸고 달력으로 돌아온다
- **THEN** 달력의 요일 머리글과 격자가 월요일 시작으로 재배치되어 있다

#### Scenario: 재실행 후 유지
- **WHEN** 주 시작 요일을 월요일로 바꾼 뒤 앱을 다시 연다
- **THEN** 달력은 월요일 시작으로 표시된다

#### Scenario: 달력 화면에 선택 UI 없음
- **WHEN** 달력 화면을 연다
- **THEN** 주 시작 요일을 바꾸는 토글이나 선택지가 표시되지 않는다
