# Spec Delta

## ADDED Requirements

### Requirement: 패턴이 없는 날짜
현재 근무 패턴이 없으면(근무 패턴 초기화 뒤) 이력의 마지막 종료일(`until`) 전날까지의 날짜는 그날 적용되던 이력의 패턴으로 SHALL 계산하고, 그 이후의 모든 날짜는 근무가 없는(패턴 없음) 날짜로 처리한다. 이력도 없으면 모든 날짜가 패턴 없음이다. 패턴 없음은 오류가 아니며 날짜 세부 내용으로 근무를 바꾸는 규칙에는 영향을 주지 않는다(MUST). 새 패턴을 등록하면 마지막 이력 이후의 날짜가 새 패턴으로 계산된다.

#### Scenario: 이력 없음·패턴 없음
- **WHEN** 이력도 현재 패턴도 없는 상태에서 임의 날짜를 계산한다
- **THEN** 모든 날짜가 패턴 없음이다

#### Scenario: 이력 종료일 경계
- **WHEN** 이력의 마지막 항목이 패턴 A를 `2026-10-13` 전날까지로 기록하고 현재 패턴이 없다
- **THEN** `2026-10-12`는 패턴 A로 계산되고 `2026-10-13`부터는 패턴 없음이다

#### Scenario: 다시 등록
- **WHEN** 위 상태에서 새 패턴 B를 등록한다
- **THEN** `2026-10-12` 이전은 패턴 A, `2026-10-13` 이후는 패턴 B로 계산된다
