# Spec Delta

## MODIFIED Requirements

### Requirement: 기존 달력 화면 요소 유지
요약을 추가한 뒤에도 달력 격자, 월 이동, 하단 조작 요소(바로가기 줄과 대체 [설정] 버튼), 배너 광고 영역은 기존과 같은 순서와 동작으로 SHALL 표시되며, 360px 폭에서 가로 스크롤이 생기거나 요소가 겹쳐서는 MUST NOT 된다. 배너 광고와 그 바로 위 조작 요소 사이의 간격 규칙은 그대로 지켜져야 한다. 요약 카드는 자체 광고 요소나 자사 유도 요소를 포함해서는 MUST NOT 된다.

#### Scenario: 좁은 화면
- **WHEN** 360px 폭에서 달력 화면을 연다
- **THEN** 요약 카드 두 개가 한 줄 또는 두 줄 안에서 잘림·겹침 없이 표시되고 달력 격자 7열이 모두 보인다

#### Scenario: 광고 간격
- **WHEN** 달력 화면을 끝까지 스크롤한다
- **THEN** 하단 조작 요소와 배너 광고 사이 간격이 기존 규칙(32px 이상)을 지킨다

#### Scenario: 광고 없음
- **WHEN** 광고가 로드되지 않는다
- **THEN** 요약과 나머지 요소는 정상 표시된다
