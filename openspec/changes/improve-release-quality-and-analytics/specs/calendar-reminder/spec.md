# Spec Delta

## MODIFIED Requirements

### Requirement: 캘린더 알림 안내
캘린더 알림 화면은 턴캘이 파일에 알림을 넣고, 실제 알림은 사용자가 파일을 가져온 캘린더 앱에서 울린다는 점을 SHALL 안내한다. 알림 대상은 주간·오후·야간·당직이며 비번·휴무는 제외한다. 토글을 꺼도 캘린더 앱의 기본 알림이 따로 붙을 수 있음을 SHALL 표시한다. 이미 가져온 일정에 바꾼 설정이 자동 반영되지 않으며, 다시 가져왔을 때의 갱신·중복·알림 결과를 확인하도록 SHALL 안내한다. 외부 앱의 갱신이나 알림 제거를 보장해서는 MUST NOT 된다.

#### Scenario: 안내
- **WHEN** 캘린더 알림 화면을 연다
- **THEN** 파일에 추가하는 알림과 실제 캘린더 앱 알림의 차이, 비번·휴무 제외, 기본 알림 가능성, 설정 변경 뒤 외부 일정이 자동으로 바뀌지 않는다는 안내가 보인다

#### Scenario: 이미 가져온 일정 안내
- **WHEN** 알림 설정 화면에서 기존 캘린더 일정의 갱신 안내를 읽는다
- **THEN** "설정을 바꿔도 이미 추가한 일정은 자동으로 바뀌지 않아요. 다시 가져와도 기존 일정은 그대로라서, 그 달 일정을 지운 뒤 가져와 주세요."가 보이며, 다시 보내기만 하면 기존 일정이 반드시 수정된다고 안내하지 않는다
