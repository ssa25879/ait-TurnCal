# 턴캘 (TurnCal)

교대근무 반복 패턴을 등록하면 월간 달력에 근무를 자동으로 보여 주는 앱인토스 미니앱이에요. 근무표·메모·설정은 기기에 저장하고, 패턴 저장·내보내기 행동은 Apps in Toss SDK로 기록해요.

## 주요 기능
- 근무 패턴(주간·오후·야간·당직·비번·휴무)과 기준일로 월간 달력 자동 계산
- 달력 위쪽에 오늘·내일 근무 요약(바뀐 근무·시간·공휴일 이름 포함, 누르면 그 날짜 화면)
- 근무 패턴을 바꿀 때 적용 범위 선택(오늘부터 / 전체 기간), 패턴 이력 확인과 예전 근무 순서 불러오기
- 근무 유형 6종의 이름·한 글자 약어·색 변경
- 보고 있는 달의 근무표를 달력 이미지(PNG)나 캘린더 파일(.ics)로 내보내기
- 캘린더 파일에 근무 전날 저녁 알림 포함(18~23시 선택·끄기 가능, 비번·휴무 제외). 파일을 캘린더 앱에 추가하면 해당 앱에서 알림이 울려요
- 날짜별 세부 내용·메모, 근무표·사용자 이름, 주말·공휴일(2026~2035) 표시
- 화면 설정(색 테마 3종, 주 시작 요일), 항목별·전체 초기화
- 달력 하단 배너 광고, 앱 시작 시 사용자 식별키 저장(화면에 표시하지 않음)

## 출시 상태
- v1.3 `20261021-27` 출시 완료(2026-10-21 사용자 확인): 캘린더 파일 전날 저녁 알림, 같은 달 재내보내기 시 파일 이름 중복 오류 수정
- 2026-10-26 콘솔에서 라이브 버전과 상세 설명·미리보기 8장 반영을 확인했어요. 출시 기록은 `docs/NEXT_STEPS.md`를 참고해요.

## 사용 행동 기록

- 패턴 저장 성공은 `turncal_pattern_saved`, 내보내기 시작은 `turncal_export_requested`, SDK 결과 반환은 `turncal_export_result`로 기록해요.
- 앱이 보내는 속성은 내보내기 형식(`image`·`calendar`)과 결과(`opened`·`failed`·`unsupported`)뿐이에요. 이름·날짜·근무 패턴·메모·파일 이름·오류 내용·저장한 식별키를 이벤트에 넣지 않아요. SDK가 자동으로 붙이는 공통 속성에는 `anonymous_key`가 포함될 수 있어요.
- `opened`는 공유 요청이 오류 없이 반환됐다는 뜻이에요. 공유 취소와 실제 전송·저장·가져오기 완료를 구별하지 않아요. 분석 오류나 응답 지연은 저장·내보내기를 막지 않아요.

## 개발

Node.js 24 이상을 사용해요. SDK와 개발용 Devtools는 3.9.0으로 고정해요.

```bash
npm install
npm run dev          # 개발 서버 (Devtools mock)
npm run typecheck
npm test             # 단위 테스트
npm run test:tz      # 시간대별(서울·뉴욕·UTC) 테스트
npm run build        # 실제 광고 ID 번들 (.env.production.local 필요)
npm run build:adtest # 테스트 광고 ID 번들 — 실기기 테스트용
```

- 실제 광고 ID는 `.env.production.local`(커밋 금지)에만 둬요. 테스트에는 `build:adtest`를 써요.
- 브라우저 E2E는 `scripts/e2e/README.md`를 참고해요.
- 플랫폼 설정은 `apps-in-toss.config.ts`에서 관리해요.
